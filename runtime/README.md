# 桌面端内置运行时

这里是 hqyl_desktop 自己维护的业务代码与公共配置模板，不是其他项目的链接。

迁入范围依据已公开发布的 1.0.6 安装包核对：43 个紫鸟相关 Python 模块、25 个马帮工具文件和 6 份公共配置。紫鸟模块与安装包实际冻结模块一一对应；未加载的旧脚本、其他独立应用以及其中的人员配置不迁入。

业务代码沿用验收版本，仅规范文本换行；本次隔离不更改充值判断、状态写回、付款步骤或既有业务参数。马帮工具清单在 `scripts/public_mabang_inputs.json`，对应 SHA-256 也在本仓库维护。后续业务修复直接修改这里，不从其他项目自动同步。

账号、Cookie、真实人员映射不放在此目录；沿用用户 settings、运行时登录及已授权安装包配置。工具中的资产名称只是取得运行时凭据的引用，不是密码本身。
