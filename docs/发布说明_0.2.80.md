# 0.2.80 发布说明

日期：2026-10-21。

## 源码来源

按项目约定从 `https://github.com/yyl152765/hqyl_desktop.git` 的独立检出执行 `git pull --ff-only origin main`，结果为 `Already up to date.`，上游提交为 `39bf912453cf6a6e554779ef1deb7aff522b4af0`。父仓库 `hqyl_project` 的提交与桌面上游分开记录。当前源码包含保留的本地修复，本轮没有创建新的 Git 合并提交，也没有推送源码。

## KEC 迁移与报价兼容

将旧版 KEC 业务流程接入桌面端「财务流程 → KEC 对账」，继续使用平台绑定的马帮账号，支持配置马帮域名。旧 EXE 与本地配置中的凭据不迁入应用。

本轮使用用户提供的 2026-09-01 生效报价工作簿进行只读解析与规则验证。它包含报价、索赔标准两张表，没有本月账单明细和人工核对结果。用户明确同意报价解析、规则边界和模拟完整账单验证通过后打包。

报价表三档首票写着含4、5、6件；用户再次确认仍按此前口径：**所有档位首票均含3件**，不采用该三处含件数。第20件起仅增量部分每件0.3元，前19件按本档首票与续件价计算。该差异保留在验收记录中。

已实施的计费条款：

- 仓租以实际长宽高和数量计算。9–12月均免租60天，超60天1.5元/立方米/天；其他月份仅日均≥3000单采用此档，其余保留旧档位。
- 日均超过2000至3000单首票1.4元，超过3000至5000单1.3元，超过5000单1.2元，均含3件且常规续件0.5元。≤2000单保留旧档位与0.6元续件。第20件起按增量0.3元。
- 退件每单2元含3件，超出每件1元，同订单多SKU不重复收首票。
- 退仓1.1元/件；散货装卸27元/方，正数方数向上取整。

新版报价增加了仓租和操作费行，并将包材代码列后移。解析需要按表头、分类和代码定位，不能将旧固定坐标套在新报价上。新旧报价均须保留免费文本识别及无效费率报错；本次明确修订的条款优先于报价。中文尺寸表头、前置标题、缺日期、未知退件数量和非退件标记均有明确处理。
