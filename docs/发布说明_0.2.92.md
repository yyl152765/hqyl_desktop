# 0.2.92 TEMU 财务导出启动入口修复

0.2.91 原生桌面导出先导航全球卖家中心并调用其登录流程；在该流程出现“获取公钥失败”时，程序尚未进入中国卖家中心对账页便终止。此前 CLI 使用已登录页面，未覆盖这个原生启动路径。

本版直接以中国卖家中心对账页为财务导出目标，去掉无关的全球中心登录前置步骤。账号权限、紫鸟店铺 ID、代理检测和对账页的登录/身份检查继续执行；需要时仍在全球明细下载阶段核对同一店铺并处理确认。

新增原生浏览器启动链回归，证明全球登录失败不会阻止进入所需中国页面。保留 0.2.91 的表单等待和下载确认界面兼容。真实店铺登录失效或网站请求失败仍可能阻止导出，本版软件内完整流程尚待实店验收，不将之前的 CLI 成功计作本版桌面验收。

安装后重启客户端，再按原店铺和日期创建新批次；旧批次和原始文件保留。
