# 1.0.2 桌面版发布说明

更新中心通过发布服务器读取版本信息、下载并校验安装包。已保存旧官方更新地址的客户端升级后自动使用新地址。自定义更新源继续使用原配置。

服务器管理员可解压 `HQYLAutomation_ServerUpload_1.0.2.zip`，运行 `部署更新源.bat`。部署完成后，尚未升级的同事可在「设置 → 更新中心」粘贴下列完整地址，点「检查更新」并选择下载安装。旧版识别地址时需要保留 `:80`。

```text
http://47.112.20.68:80/hqyl/latest.json
```

也可以直接运行 `HQYLAutomationSetup_1.0.2.exe` 升级。菲律宾 Shopee 取消订单同步退款仍在「马帮流程」中。
