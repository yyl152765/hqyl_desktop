# 寰球云联自动化平台 0.2.50 发布说明

发布日期：2026-09-05。升级版本：`0.2.49` → `0.2.50`。

## 更新内容

- 侧栏采用紧凑模块列表，支持分组折叠、模块搜索和 `Ctrl+K` 快速定位。
- 支持最多 5 个常用入口，并保存常用模块与分组展开偏好；搜索和工作台入口固定在顶部。
- BigSeller 登录按官网规则清理账号、密码首尾空白，保留内部空格，修复网页可以登录但客户端登录失败的问题。
- BigSeller 对标暂停时显示明确且已脱敏的登录失败原因，保留已保存进度，方便处理后继续补查。

## 升级及使用

安装 `HQYLAutomationSetup_0.2.50.exe`。账号、验证码服务及导航偏好继续使用用户配置目录，安装包不携带开发机账号、密码或任务数据。

BigSeller 原有进度文件可继续使用。恢复时选择创建该进度时的账号、原源文件、工作表和指标；“结果不完整”的导出表不是恢复所需的原源文件。

## 更新源部署

服务器上传包解压后，核对 `deploy.ps1` 中的目标目录，再执行 `部署更新源.bat`。默认目录为 `C:\inetpub\wwwroot\hqyl`；脚本先校验并复制安装程序，最后更新 `latest.json`，保留原清单备份。
