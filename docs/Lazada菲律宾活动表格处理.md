# 通用 Excel 折扣筛选说明

批量导入本地 Excel，识别原价、活动价和推荐价，按最低折扣率筛选；可选导入SKU价格表，再筛除低于参考价格的商品。工具直接处理本地文件，无需配置账号、紫鸟客户端或活动链接，结果与审核明细另存。

## 使用步骤

1. 进入「通用工具 → Excel 折扣筛选」页面。
2. 批量选择需要处理的 `.xlsx` 或 `.xlsm` 文件，也可填写文件完整路径。每批最多100份，重复路径自动去除。
3. 如需增加SKU底价限制，在活动文件列表下单独选择一份「SKU价格表」。不选择时，保持原来的折扣筛选规则。
4. 选择价格处理方式：自动识别、按已有活动价筛选，或按推荐价填充并筛选。可先检查表头识别、异常行数量，以及参考表的SKU条数。
5. 输入最低折扣率，例如95%，并选择结果保存目录。
6. 开始处理，查看每份文件的填价、保留、折扣剔除、SKU价格剔除和异常行数。
7. 打开处理后的表格、审核汇总或 ZIP。所有结果另存到新的批次目录，源文件不修改。

单文件最多50 MiB，每工作表最多100,000行、200列。一个工作簿可以包含多个待处理工作表，其余说明工作表保留。单文件失败会记录原因，其他文件继续处理。

## 导出空白模板

选择本地保存目录并导出模板，在空白工作表中填写自己的数据后重新导入。标准表头为：

也可直接使用仓库中的 [Excel折扣筛选模板.xlsx](templates/Excel折扣筛选模板.xlsx)。

| SKU | 商品名称 | 原价 | 活动价 | 推荐价 |
| --- | --- | --- | --- | --- |

「按已有活动价筛选」需要有效的原价和活动价；「按推荐价填充并筛选」还需要推荐价列。SKU和商品名称用于标识商品，原有文本、前导零及其他业务列随保留行一起保存。

价格填写正数。推荐价支持普通数值、`<=95`、`≤95`，以及 `0 < Price <= 95`、`0 < Price ≤ 95` 这样的范围。程序取可提报价格的上限（示例为95）作为填充价格，然后计算折扣率；推荐价原单元格保持原样。无法明确识别上限的文本记为异常，不从任意文本中猜测价格。不要在价格列保留需要重新计算的公式；可在 Excel/WPS 中先粘贴为数值。

## 价格处理方式

- **自动识别**：通用「原价」表头使用已有活动价，推荐价列存在时也不会自动覆盖活动价。识别出特邀模板时，使用推荐价填充活动价。识别出「售价 / 大促价格（必填） / 推荐价格」等普通活动模板时，先沿用已有活动价；活动价为空时，优先使用该行非空的最高活动价，再从推荐价取上限填入活动价。最高活动价非空但无效或为公式时，该行记为异常，不跳过该值改用推荐价。
- **按已有活动价筛选**：使用表格中的活动价计算比例，保留原值。推荐价仅作参考。
- **按推荐价填充并筛选**：将有效推荐价写入活动价，再计算比例。推荐价为空时沿用已有的有效活动价；两者都缺失时记为异常。原文件不变，填价只发生在结果副本中。

工具识别常见中英文价格表头，例如「原价」「活动价」「市场活动价」「推荐价」及 `Original Price`、`Campaign Price`、`Recommended Price`。新版中文特邀表的「市场活动价」按活动价处理，「流量加权价」不参与填价；推荐价格按实际表头定位，不限定在H列。缺少关键列或关键价格表头重复时，检查结果会给出原因；自动识别的处理方式不符合预期时，可选择明确的方式后重试。

已有 Lazada 特邀和普通表格也可作为本地 Excel 导入。例如普通表的售价为100、活动价为空、推荐价格为 `0 < Price <= 95`，自动识别后活动价填95，最低折扣率95%时保留。活动价已经填写时沿用原值；选择「按已有活动价筛选」始终不自动补价，空价格记为异常。活动表的中英文说明行保留，不计入商品数据行；本工具不下载或提交店铺活动。

## 折扣与异常规则

折扣率 = 活动价 ÷ 原价。低于输入阈值的行移出结果表，等于阈值时保留。页面95%对应接口参数 `0.95`，表示活动价至少为原价的95%。

| 原价 | 活动价 | 比例 | 最低折扣率95%时的结果 |
| --- | --- | --- | --- |
| 100 | 95 | 95% | 保留 |
| 100 | 94 | 94% | 折扣筛除，写入审核明细 |
| 0 | 95 | 无法计算 | 异常，写入审核明细 |

无有效价格、原价为零、价格公式及其他无法核算的行移入审核明细。结果表只保留可以验证的合格行，审核文件记录源文件、工作表、原始行号、处理原因和原行数据。

删除可能影响仍保留的引用公式时，该文件明确失败；将公式粘贴为数值后重试。保留行的字体、格式、行高、隐藏状态、批注、超链接和常量公式随行移动，合并区域、表格及数据验证范围按结果行数调整。

## 可选SKU价格表

单独选择或粘贴一份 `.xlsx` / `.xlsm` 参考表路径，至少包含「SKU」「价格」两列，例如：

| SKU | 价格 |
| --- | --- |
| 0001 | 96 |
| 0002 | 95 |

筛选顺序为：先按原有最低折扣率筛选，再对通过折扣的商品按卖家SKU或SKU精确匹配参考表。命中且活动价低于参考价格时移出结果；相等、更高或未匹配时保留。活动价95、参考价96会被SKU规则剔除；参考价95则保留。活动表的 `Sku ID`、店铺SKU不代替卖家SKU匹配；启用参考表但活动表缺少可识别的卖家SKU/SKU列时会明确失败。

SKU只去除首尾空白，区分大小写并保留文本中的前导零、符号。活动表空SKU按未匹配处理，通过折扣后保留；SKU含公式、Excel错误或不合法数字时，该行移入异常明细。建议将SKU列设为文本，避免长数字在Excel中丢失精度。参考表的价格必须为有效正数，并与活动价使用同一币种，程序不自动换汇；空值、无效价格或公式需先修正。同一SKU重复且价格相同会合并；价格不同视为冲突，检查与启动都会报出位置并阻止本批处理，不自动选取其中一个价格。

「移出结果」总数包含折扣剔除、SKU价格剔除和异常行，三类分别统计，审核明细记录剔除原因。参考表和活动原文件均不修改；点击「移除」清空参考路径后恢复只按原有折扣规则筛选。处理期间参考文件选择、路径编辑与移除均禁用。

处理完成后，每份文件右侧的「SKU价格剔除（N）」可查看通过折扣筛选后，因活动价低于SKU参考价格而剔除的商品。面板显示SKU、活动价、参考价格、工作表、原始行号与原因，最多预览前100行；同一SKU在不同来源行出现时分别记录，不去重。折扣剔除和价格异常不包含在这份删除SKU明细中，可在「汇总与异常明细」查看。结果列以「① 折扣剔除」「② SKU价格剔除」标注顺序。

点击面板内「导出 Excel」，在保存对话框选择位置，将该文件的全部SKU剔除明细另存为 `.xlsx`。导出包含超过预览数量的所有明细，SKU按文本保存以保留前导零。保存对话框取消不会报错，也不会更改已有文件。页面重载、切换回工具后仍可重新打开明细并导出；输入文件变更或重新处理会关闭旧明细，避免混淆批次。关闭按钮或Esc关闭面板并返回原按钮焦点，点击另一份文件的按钮可直接切换明细。

每份完整删除SKU明细也自动保存在批次目录并加入ZIP。若完整明细文件保存失败，已经生成的筛选Excel与预览仍可查看，任务会提示不完整，明细导出暂时禁用。旧任务没有明细字段时不会出现查看按钮；界面演示只展示示例，不提供真实导出。

前端会检查后端是否支持SKU筛选。旧后端会禁用参考表输入；恢复的任务若含参考路径也会明确提示重启或升级，避免静默忽略参考表。安装版需使用包含该处理功能的匹配后端，单独刷新前端页面不会更新安装包内的筛选引擎。

## 输出与任务恢复

每批生成独立目录，保存每份处理后的 Excel、处理汇总与审核明细，以及打包文件。文件名相同的输入会分配独立结果名称，避免覆盖；原始文件始终保留在其原位置。

部分文件失败或汇总、ZIP导出失败时，任务标为不完整，已生成的结果仍可打开。根据逐文件失败原因修正后重新导入即可。

页面重载或切回工具时，仅恢复 `local_excel` 流程的任务、输入文件、可选SKU价格表路径及处理参数。旧任务没有参考表路径时按未启用处理。旧活动下载任务不会恢复到本页面，任务不关联账号。

## 接口与实现位置

接口沿用原有命名，参数和任务流程已改为通用本地 Excel：

```text
get_lazada_campaign_workbook_info()
choose_lazada_campaign_files()
choose_lazada_campaign_sku_price_file()
inspect_lazada_campaign_files({source_files, sku_price_file, mode, threshold, output_dir})
export_lazada_campaign_template({output_dir})
start_lazada_campaign_workbook({
  source_files: ["C:/表格/商品价格.xlsx"],
  sku_price_file: "C:/表格/SKU价格.xlsx", // 选填，空字符串或省略表示不启用
  mode: "auto" | "plain" | "invited",
  threshold: "0.95", output_dir: "C:/表格/筛选结果"
})
get_task_status(task_id)
get_latest_task_status("lazada_campaign_workbook")
export_lazada_campaign_removed_skus({task_id, file_index})
open_path(result_path)
```

`source_files` 为1至100个本地文件路径，`threshold` 必须大于0且不超过1。`sku_price_file` 为可选的独立参考表路径，不能与活动输入文件相同。检查结果的 `sku_reference` 提供 `enabled`、`source_file` 和去重后的 `sku_count`；无效参考表返回 `ok: false`。`sku_removed_rows` 分别记录各工作表、文件和批次因SKU底价剔除的行数，`removed_rows` 仍只记录折扣剔除。

任务context使用 `workflow: "local_excel"`，仅保存文件路径、可选参考表路径、模式、阈值和输出目录。`get_lazada_campaign_workbook_info()` 的 `supports_sku_price_filter: true` 表示后端支持该功能。启动、检查和模板导出不需要账号参数。

每份结果的 `removed_sku_preview` 为前100行预览，字段为 `sku`、`worksheet`、`source_row`、`activity_price`、`reference_price`、`reason`；预览价格为字符串，`sku_removed_rows` 为全部剔除行数。`removed_sku_file` 指向该文件的完整 `.xlsx` 明细。`supports_removed_sku_export: true` 表示后端支持保存导出；导出API只接收任务ID和从0开始的文件序号，弹出本机保存对话框后复制任务已生成的完整明细，不从前100行预览重新拼接文件。

旧接口的 `regular` 模式保留兼容，按普通活动模板处理（已有活动价优先，空价先用该行最高活动价，该值空白再从推荐价取上限填充）；新页面提供 `auto`、`plain`、`invited` 三种选择。

- `backend/services/lazada_campaign_workbook.py`：表头识别、空白模板、填价、折扣筛选与审核明细。
- `backend/app_bridge.py`：文件选择、检查、模板导出、异步批处理与操作互斥。
- `frontend/pages/lazada-campaign-workbook.html` 及同名JS/CSS：本地 Excel 工具界面。

直接启动页面：

```powershell
python desktop_entry.py --page=lazada-campaign-workbook
```
