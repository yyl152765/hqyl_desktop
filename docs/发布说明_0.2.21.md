# 发布说明 0.2.21

发布日期：2026-07-24

## EchoTik 无关键词采集

- 搜索关键词改为可选；留空时按“全部商品”范围采集，仍可组合商品类目、销量、播放量等筛选条件。
- 全部商品模式不再向 EchoTik 商品列表接口发送空的 `keyword` 参数。
- 新增“每个范围最多商品”设置，允许 1–10,000，默认 200，避免全库模式直接触发海量达人请求。
- 未填写关键词且未设置商品筛选时，启动前会明确提示预计采集范围并要求确认。
- 运行日志、结果预览、Excel 文件名和筛选摘要统一使用“全部商品”标记。
- 商品分页达到设置上限后立即停止，不再读取剩余无关分页。

## 验证结果

- 真实 EchoTik 全部商品范围验证通过：设置上限 75，返回 75 行、75 个唯一商品、0 个空商品 ID。
- EchoTik、前端完整性和版本一致性专项测试：36 项通过。
- 完整自动化测试：268 项通过。
- 前端 JavaScript 语法检查、Python 编译检查和 Git 差异检查通过。

测试命令：

```powershell
py -3 -m unittest discover -s tests
```
