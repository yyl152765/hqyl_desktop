# 0.2.88 手动可选更新

客户端更新完全自愿，不更新也可继续使用。即使服务器清单包含 `mandatory: true`，客户端仍按可选更新处理。

启动客户端、切换业务页面或打开设置时不自动检查、下载或安装。用户进入「设置 → 更新中心」，点击「检查更新」查看版本；只有再点击「下载并安装」，才下载、校验安装包并打开安装程序。检查失败不会阻止保存配置、账号操作或使用当前版本。

本版保留 0.2.87 的 Lazada Ads 截图修复、余额统计、受限账单流程、钉钉配置与操作人选择、国家店号简称匹配及紫鸟 V6 支持。内部业务依赖沿用上一版封存输入，保留个人配置和旧发布产物。

安装包、服务器上传包、SHA256 和构建验证清单位于 `release`。服务器上传包中的 `latest.json` 设置为 `mandatory: false`；上传时先放置并校验安装包，最后发布更新清单。新客户端对强制标记的忽略规则需要用户先安装本版才会生效；本地修改不会直接改变已安装的旧客户端。

本次交付本地构建产物，不执行服务器上传、部署或覆盖用户现有安装。源码来源、上游核对结果、工作区提交、未提交改动、签名状态及实际验证范围以同版本 `BUILD_MANIFEST` 和 `PACKAGE_VERIFICATION` 为准。
