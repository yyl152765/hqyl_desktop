# 寰球云联自动化平台 0.2.54 发布说明

发布日期：2026-09-11。升级版本：`0.2.53` → `0.2.54`。

## 更新内容

- 修复 TEMU 批量设置过程中，本地进度文件发生 `WinError 5：拒绝访问` 的问题。界面进度读取与后台保存共用文件读写锁。
- 外部程序短暂占用进度文件时自动进行有限重试；持续无法保存时暂停任务，保留原进度，不继续提交后续渠道。
- 恢复时先核对实际设置，已提交且符合目标的渠道不重复提交；进度尚未保存时不误报整批完成。
- 保持按顺序处理已开启（ON）渠道、关闭（OFF）渠道不占 Excel 行，以及取消 Excel 缓存日期限制的规则。

## 升级及恢复

正常退出旧版程序，再安装 `HQYLAutomationSetup_0.2.54.exe`。选择原来的马帮账号，进入「TEMU 发货渠道更改」，点击「继续未完成渠道」即可沿用原有数据和对应关系。无需删除进度文件，也无需重新导入或预览。

## 发布及部署

- `HQYLAutomationSetup_0.2.54.exe`：客户端安装程序。
- `HQYLAutomation_ServerUpload_0.2.54.zip`：服务器上传包，含安装程序、更新清单、SHA-256、构建清单和部署脚本。
- `HQYLAutomation_0.2.54.zip`：客户端分发包。

服务器上传包解压后运行 `部署更新源.bat`，默认发布到 `C:\inetpub\wwwroot\hqyl`。若目录不同，先修改 `deploy.ps1` 中的 `$SiteRoot`。脚本先复制并校验安装包，再更新 `latest.json`，保留旧清单备份。

本次交付本地发布包，未执行服务器部署或真实渠道保存。
