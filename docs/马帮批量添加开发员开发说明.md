# 马帮批量添加开发员

## 使用

从工作台或侧栏「马帮 → 批量添加开发员」进入，选择已绑定的马帮账号，一行输入一个员工姓名（与员工列表中的显示姓名一致），点击「预览检查」。检查匹配员工、已有岗位、商品查看方式和待执行操作，再点击「批量保存」。单次最多 100 名，重复姓名自动去重。

开发环境可通过 `.\.venv\Scripts\python.exe desktop_entry.py --page=mabang-developer-permission` 打开。

## 操作范围

按截图执行两个字段的更新：

1. 保留原有岗位，追加「开发员」。
2. 将「查看商品 → 库存 SKU」的查看方式设为「按商品父目录查看」。

保留商品父目录的原有勾选项，包括 EB 产品的当前状态；保留父目录与仓库联动、各类仓库、订单、店铺、部门和角色等其他有效表单字段。该功能与仓库权限开通的目录同步规则独立，不需要选择仓库。

## 实现与验证

- `backend/services/mabang_developer_permission.py`：动态识别开发员控件、解析实时表单、预览和批次保存。
- `backend/services/mabang_warehouse_permission.py`：复用隔离浏览器会话、员工搜索和保存请求，共用完整表单读取。
- `backend/app_bridge.py`：账号解析、后台任务和有效期 30 分钟的一次性预览凭据。预览必须与当前账号和员工名单相符。
- `frontend/pages/mabang-developer-permission.html` 与对应 JS：名单输入、预览差异、逐员工结果、日志和任务恢复。

只处理唯一精确匹配且正常启用的员工。同名、未找到、停用、关键控件缺失均不会进入保存。保存前重新读取权限，发现岗位、角色、部门或权限与预览不一致时要求重新预览。已满足目标的员工跳过。

保存使用页面实际 `staff.doUpdateEmployee` 地址，提交 UTF-8 URL 编码再 Base64 编码的完整有效表单。成功响应后回读验证目标字段和原有受保护字段；保存请求失败或结果不明确时不自动重试写请求。

密码使用现有账号管理，只在后台登录时使用，不写入源码、预览或业务日志。预览快照只记录权限摘要，不包含完整表单。
