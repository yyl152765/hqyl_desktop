# 发布说明 0.2.23

发布日期：2026-07-25

## Shopee WORLD 卡短信验证码热修

- 修复 WorldFirst 短信商户名由旧格式 `FOR SHOPEE` / `TH SHOPEE MARKETPLACE` 改为 `SHOPEE` 后，正确验证码被过滤、页面一直停留在空白 OTP 输入框的问题。
- 泰国、马来西亚 WORLD 卡流程同时兼容新旧商户名格式。
- 实现层保留 `SHOPEE` 兜底关键字，即使用户本机仍保存旧版运行配置，也能识别新短信模板。
- 继续使用 SIM、短信平台、请求时间、币种和交易金额共同筛选验证码，避免跨交易误取码。

## 问题确认

- 截图中的 `THB 3424.00` 验证码短信已正常入库并包含完整 6 位 OTP，但旧商户关键字均不匹配，因此程序在短信筛选阶段跳过该记录，尚未执行验证码回填。
- 当天抽查的 52 条泰国交易 OTP 短信全部使用新商户名 `SHOPEE`，旧关键字命中数为 0，确认这是短信模板系统性变更，不是单店偶发问题。
