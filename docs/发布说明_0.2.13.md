# 发布说明 0.2.13

发布日期：2026-07-11

## 本次变更

- **并发冲突防护**：为越南 Shopee 补贴采集、广告联盟采集、马帮收支/退款明细及报表生成任务增加并发执行锁保护，防止同批次任务重复执行导致数据异常。
- **越南收支报表优化**：
  - “越南 Shopee 收支核对最终文件处理”任务更名为“越南 Shopee 收支报表生成”。
  - 新增越南收支报表仪表盘 API，支持拉取配置、异常检测、批次历史列表等。
- **健壮性修复**：修复了 Shopee 广告充值测试用例由于 `sys.path` 残留而引起的断言失败问题。
