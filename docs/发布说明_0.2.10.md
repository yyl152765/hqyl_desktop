# 发布说明 0.2.10

发布日期：2026-07-09

## 本次变更

- Shopee 广告充值新增银行卡类型传递与 WORLD 卡支付流程支持。
- 修复马来、泰国 WORLD 卡支付需要 WorldFirst 短信验证码时的自动收码、回填和支付结果等待。
- 兼容 WorldFirst 直接进入 OTP 输入框、不出现“获取短信验证码”按钮的页面状态。
- 泰国 WORLD 短信商户名兼容 `FOR SHOPEE`，修复验证码查不到导致卡在 OTP 页的问题。
- 马来 WORLD 短信商户名增加多关键字兜底，提升后续短信格式变化时的稳定性。
- 自定义充值成功后仅在成功状态登记在线表格，失败不登记；旧钉钉表格接口失败时增加 `spreadsheetv2` 的 DWS 兜底路径。

## 现场验证

- 马来 `马来259` 使用 WORLD 充值 `157.6 MYR` 成功，余额 `741.88 -> 899.88`。
- 泰国 `泰国461` 使用 WORLD 充值 `600 THB` 成功，余额 `39000.00 -> 39600.00`。
