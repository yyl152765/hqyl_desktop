# 发布说明 0.2.19

发布日期：2026-07-23

## EchoTik 二级类目

- 商品类目和达人带货类目新增二级类目选择。
- 有子类目的一级类目支持展开，并显示二级类目数量。
- 可以选择“全部一级类目”，也可以选择一个或多个更精确的二级类目。
- 同一类目组内一级类目与二级类目自动互斥，避免重复、冲突的筛选条件。
- 商品二级类目 ID 直接传给 EchoTik 商品库服务端筛选；达人二级类目按返回的达人类目在本地过滤。
- 类目加载状态同时显示一级、二级类目数量。
- 优化展开区域的桌面及窄屏布局，避免二级类目拥挤和页面横向溢出。

## 验证结果

- 真实 EchoTik 类目接口验证通过：29 个一级类目、239 个二级类目。
- 二级类目选择、一级/二级互斥、筛选摘要和重置操作验证通过。
- 桌面布局及 720px 窄屏布局验证通过，无横向溢出。
- 页面控制台无错误。
- 完整自动化测试：261 项通过。

测试命令：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
