# 发布说明 0.2.9

发布日期：2026-07-07

## 本次变更

- 修复 Shopee 越南仓发店广告充值后浏览器会话断开时长时间空等的问题。
- 充值提交后会话断开改为“处理中”，延迟重新开店复查广告余额。
- 充值前余额读取增加刷新重试，减少 `stale element reference` 导致的空余额。
- 充值后支持两次余额确认，两次间隔 45 秒；未确认到账时不重复提交支付。
- 处理中的充值保留额度占用，防止后续批次重复充值。

## 现场验证

- `寰球雲仓发越南001` 充值 `8,000,000 VND` 成功，广告余额增加约 `8,000,000 VND`。
- `天穹仓发越南002` 支付失败后两次复查未到账，流程没有重复提交。
