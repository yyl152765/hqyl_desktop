# 0.2.67 桌面客户端

本版修复印尼 Shopee 广告充值数据采集中的“待核验”问题：

- 采集七天消耗前切换到 Product Ads，并验证页签和报表类型，避免默认 Shop+ Ads 导致报表不匹配。
- 增加印尼语 Saldo Iklan（余额）和 Biaya Iklan（消耗）标签识别。
- 采集失败按消耗、钱包、余额或证据阶段给出原因；空快照不再误报为站点或币种不匹配。日期、金额、站点、币种和人工金额审核仍然严格校验。

安装后需重新运行数据采集核验，安装本身不会清除表内待核验标记。四条人工固定充值金额仍需人工审核。本次未提交付款或修改表格；此前仅对两个页面样本做只读验证，未宣称所有待核验店铺均已实测恢复。

发布副本移除充值防重模块中旧的内置数据库密码。运行电脑需提供 `HQYL_GUARD_DB_PASSWORD`，或通用 `PGPASSWORD` 环境变量；数据库同步模块仍使用 `PGPASSWORD`。包内不包含密码。保留本地开发原配置。
