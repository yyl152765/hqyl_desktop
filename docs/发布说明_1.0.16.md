# 1.0.16：商品销量报表新版兼容与完整性修复

发布日期：2026-11-28。

- 各组销量、商品仓库按月导出、开发员与销售员收入汇总支持马帮新版 SPA，并保留旧版页面兼容。按账号实际页面选择协议，读取失败不会被误判为旧版或零收入。
- 修正分类与仓库交集、多仓合并、完整分页、41 列映射及金额/比例精度。商品资料按 SKU 与商品 ID 核对，item_id 保持文本；缺列、截断、身份冲突或可见统计范围变化时明确失败。

- 登录 HTTP 403 区分入口、提交、会话确认阶段。部分月份失败明确显示结果不完整，保留已成功月份文件。
- 保留 ERP SKU 查询的授权连接能力，将旧本地发布分支中的连接字面量改为构建时注入私有资源；公开源码与提交历史不包含连接密码。

已完成真实账号的分类、仓库、指定人员和全部人员链路验证。上游刷新时间字段不代表不可变事务快照，不同时点的报表数据仍可能变化；不将跨时点差异误判为同一快照的财务对账结果。真实商品、内部人员、凭据及原始报表证据仅保留本地，不随源码发布。
