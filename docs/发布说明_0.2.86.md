# 0.2.86 本地修复候选包

Lazada / TEMU 余额统计在开始及重试时，先关闭当前 Windows 用户、当前会话中所选紫鸟 V6 客户端和可确认所属的店铺进程，再启动自动化模式。界面会提前说明关闭窗口的行为；请先保存紫鸟窗口中的操作。同一应用内，余额统计与其他任务互斥。页面加载和默认值检测不会结束进程。

启动过程核验进程路径、用户、会话、进程创建时间及自动化端口归属。进程未退出、外来程序占用端口或无法核实归属时保留明确错误，不继续打开店铺。新安装 V6 会等待内核准备，单次等待有上限；无法联网、代理 IP 失败和账号失效仍须处理对应原因。

打开每家店铺前按实际 Chromium 内核版本检查驱动：有效驱动直接复用；缺失、空文件、损坏或主版本不匹配时自动下载对应的紫鸟官方驱动。下载文件经过官方清单 SHA1、PE 格式和 `--version` 检查后才替换，旧文件保留备份。下载失败保留原文件，不使用半成品；权限不足、文件占用或系统架构不兼容会报告具体原因。

未安装紫鸟 V6 时，余额统计页提供“下载紫鸟 V6”“重新检测”和“选择已安装客户端”。下载按钮打开 [紫鸟官方 Windows 下载页](https://www.ziniao.com/download/?tab=win)，由用户完成安装；本安装包不包含第三方客户端、不静默安装紫鸟。自动检测支持环境变量、注册表与常见安装目录；可手动选择自定义位置的 `ziniao.exe`。

Excel 继续使用一张“余额统计”表，顺序为店铺名称、Income、Income截图、Balance、Balance截图、Ads、Ads截图、processing、processing截图，再接站点等信息。截图列只有图片，展示缩小；无处理中提现也保留 processing 状态截图。此前 Balance 动态尺寸重拍、代理 IP 检查、Lazada 受限账单、钉钉配置和店铺简称匹配修复均保留。

本次在本地工作区修复并打包，未同步桌面上游、未改写父仓库远端、未产生上游合并提交。发布清单分别记录父工作区、继承的桌面来源与依赖快照。旧 0.2.85 产物保留。当前工作区含既有修改，安装包未签名，因此标记为本地内部验收候选；没有安装到客户电脑或上传部署。

验证结果以同版本 `BUILD_MANIFEST` 和 `PACKAGE_VERIFICATION` 为准。驱动下载可使用官方源验证；客户端进程测试仅使用隔离的自有测试程序，测试不关闭使用者的真实紫鸟窗口。客户账户端到端采集仍需在其电脑安装后验证。
