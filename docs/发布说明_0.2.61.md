# 寰球云联自动化平台 0.2.61 发布说明

修复 TEMU 在售商品导出在真实紫鸟账号通道中遇到的登录和弹窗问题。操作仍为：确认设置中的紫鸟账号，每行粘贴一个完整店铺名，填写输出目录，点击“开始导出”。无需勾选店铺、刷新或匹配预览。

- 自动衔接已观察到的 TEMU 地区入口和授权登录页，使用紫鸟自动填充的店铺登录信息；需要验证码时提示人工处理。
- 关闭商品列表的已知待办提示，等待弹窗动画结束，处理提示晚于页面控件出现的情况。
- 修复 Windows 下过短的端口探测超时导致店铺已关闭却被误判未关闭。仍然一次只打开一家店，确认关闭后再继续。
- 保留文件内容严格校验、部分结果标记和失败店铺重试；不修改商品、价格、库存或上下架状态。

2026-09-17 实机验证使用平台绑定紫鸟账号：泰国009导出 12,183 行 / 2,104 个 SKC；菲律宾021修复后重试导出 3,130 行 / 651 个 SKC。汇总 15,313 行逐行核验通过，已生效、已作废、待卖家确认价格以及 4,257 行零库存全部保留。事件记录确认串行关闭，重试未再次打开成功的泰国店。

本地 172 项回归通过。源码和成品自检、包内源码与前端资源比对、ZIP 内容及校验码结果见 `HQYLAutomation_0.2.61_BUILD_MANIFEST.json` 和 `HQYLAutomation_0.2.61_PACKAGE_VERIFICATION.json`。
