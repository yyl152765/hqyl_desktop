# KEC 对账

## 使用方式

入口：财务流程 → KEC 对账。

1. 在平台设置中绑定并选择马帮账号（沿用平台已有的马帮账号，无需单独配置）。
2. 选择 KEC 供应商账单 Excel。选择后会自动读取子表清单与仓储费表的关键列，缺列或异常会立即提示，不会带着错误模板登录。
3. 需要按报价表核对时选择报价表 Excel；留空则使用程序内置报价规则。
4. 选择输出目录并开始对账。运行日志会记录读取账单、查询马帮订单与各费用表的核对进度。
5. 完成后查看对账汇总，点“打开 Excel”查看多表结果。

任务上下文绑定马帮账号，切换账号后不会恢复其它账号的历史任务。

## 核算口径（本次迁移唯一的业务变更）

**仓储费核算基数由「Total CBM within period」改为「实际体积」。**

```
实际体积(m³) = 长(CM) × 宽(CM) × 高(CM) × 数量(PCS) × 0.000001
核对金额      = 实际体积 × 库龄对应单价
```

- 长、宽、高、数量四列全部取自账单仓储费表自身，不依赖账单是否新增列。
- 账单的 `Total CBM within period` 仍然保留在结果中，但只作为对照列（`账单 Total CBM`）与体积差额的来源，**不再参与金额计算**。
- 库龄口径不变：`入库时间 → 计费时间` 的自然日数 + 1，按 ≤30 天免费 / 31–120 天 2 元 / 121–180 天 3.5 元 / 181 天以上 5.1 元（元/CBM/天）分档。
- 数量核对口径不变：仍按 `Total CBM / Unit Billing CBM` 反算数量后与账单数量比对。
- 长宽高或数量为空时**不会**按 0 静默计费：该行核对金额留空、结果标记为“异常”，并计入独立的“仓储费缺失尺寸行数”统计。

其余四项费用（卸货费、出库+耗材、退件上架费、杂费）的口径与迁移前完全一致。

### 为什么会产生差异

仓库计费体积是向上取整后的整箱/整票体积，长期大于货物真实体积。改用实际体积后，账单金额与核对金额的差额即为这部分取整带来的溢价。以 2026-02 真实账单（68,648 行仓储明细）为例：

| 项目 | 数值 |
| --- | --- |
| 账单仓储费 | 21,603.09 |
| 按实际体积核对 | 19,694.02 |
| 差额 | 1,909.07（约 −8.8%） |
| 体积差额合计 | 1,487.52 CBM |
| 缺失尺寸行数 | 0 |

即账单按计费体积多收了约 1,909 元仓租。这是本次口径调整的预期结果，不是计算错误。

口径切换后，仓储费表的**异常数会大幅上升**：凡库龄超过 30 天（即真正计费）的行，账单金额几乎都按计费体积算出，与新口径的核对金额不再相等，因此会被标记为“异常”。上例中 68,648 行里有 41,410 行如此。判断账单是否合理请看金额差额与体积差额合计，而不是只看异常数。

## 输出结构

结果文件命名为 `原账单名_核对结果.xlsx`；同名文件已存在时自动追加 `_2`、`_3` 序号，**不会覆盖历史结果**。

| 工作表 | 内容 |
| --- | --- |
| 仓储费核对 | 原始账单列 + 核对数量、核算基数(实际体积)、账单 Total CBM、体积差额、核对库龄、库龄差额、核对单价、单价差额、核对金额、金额差额、核对结果、核对说明 |
| 卸货费核对 | 按方数向上取整 × 27 元/方核对 |
| 出库耗材核对 | 回查马帮订单，核对包材费、出库操作费、续件费与总金额 |
| 退件上架费核对 | 明细按订单 + SKU 匹配，费用按订单退货总数量计算（首件 2 元、续件 1 元） |
| 杂费核对 | 仅按已覆盖报价规则核对，未覆盖费用保留待确认 |
| 汇总 | 五项费用的账单金额 / 核对金额 / 差额 / 异常数，Invoice 金额，辅助统计与口径说明 |

页面上同时展示账单仓储费、核对仓储费（实际体积口径）、体积差额（CBM）与输出文件，以及五项费用的汇总表。

## 账单体检（登录前失败）

`inspect_kec_source_workbook` 只读工作表元信息与表头，不会遍历数万行明细，因此很快。它要求：

- 仓储费表的表头**必须含** `Unit Length` / `Unit Width` / `Unit Height` / `PCS` 关键字。这里刻意不做列位兜底：一旦表头变了而位置又刚好对得上其它列，按位置取数会把钱算到错误的列上，宁可先报错让人确认模板。
- 缺少 `Total CBM` 列只产生警告，不阻塞对账（体积差额留空）。

## 限制与注意事项

- 支持 `.xlsx` / `.xlsm`。账单需包含 Invoice、仓储费、卸货费、出库+耗材、退件上架费、杂费六类子表；子表名不完全匹配时会按位置回退并在日志中提示人工确认。
- 出库与退件核对需要登录马帮回查订单与退货/退款记录。账号无权限或查询异常会体现在“未命中订单数”“待确认数”里，不能当作账单没有这笔费用。
- 单月账单仓储费明细可达数万行，完整对账约 1 分钟量级，时间主要花在仓库明细写出与马帮回查。
- 报价表提供时，未在报价表覆盖的杂费项目会保留为“待确认”，不会被默认核减。
