## 迁移来源与范围

旧独立工具的源码位于 `D:\hqyl_project\finance_process\app\modules\kec_reconciliation\`，入口为 `gui.py`，配置读写为 `gui_config.py`，业务核算为 `service.py`；旧启动入口为 `run_kec_reconciliation_gui.py`。

旧产物 `D:\hqyl_project\finance_process\dist\KEC对账工具.exe` 的 SHA256 为 `669b0c50e37f86929197222c0a47c77d94921eabe2b23de75c8bb997fe261be0`。本轮只读静态核对确认其业务 service 与旧 finance 源码对应，没有执行旧 EXE。旧 GUI 及其配置包含独立账号配置，桌面平台不搬用这些凭据或配置文件，账号统一使用平台已绑定的马帮账号。

本轮迁移补齐马帮域名入口、账单兼容检查、报价与任务参数恢复，并实施下列四项新条款。旧程序与本页面早期“仅改实际体积”的说明不再代表当前计费规则。

## 使用方式

入口：财务流程 → KEC 对账。

1. 在平台设置中绑定并选择马帮账号。
2. 选择或粘贴 KEC 供应商账单路径，支持 `.xlsx` / `.xlsm`。选择后会预览六类工作表及仓储费关键列；文件或必需列无法识别时，在登录前提示处理。
3. 可选报价表。它只调整未变更的旧仓储分档、低档操作费与包材，新条款始终优先。留空使用内置报价；显式选择但无法解析的报价表会报错，不会默默改用默认价。
4. 选择输出目录。需要其他马帮私域时，展开“高级设置：马帮域名”，填写该账号使用的 HTTP(S) 域名，可带端口，不含路径、查询参数或账号密码。
5. 开始对账，查看日志与结果汇总，完成后打开结果 Excel 或输出目录。

任务恢复沿用平台任务机制，恢复账单、报价、输出目录与域名，且只显示当前马帮账号对应的任务。任务上下文不保存账号密码；这不是跨客户端重启的任务持久化机制。

## 当前核算规则

### 仓储费

```text
实际体积(m³) = 长(CM) × 宽(CM) × 高(CM) × 数量(PCS) × 0.000001
核对金额 = 实际体积 × 适用库龄单价
库龄 = 入库日期至计费日期的自然日数 + 1
```

- 账单计费月为 9–12 月时，不论日均单量，库龄 60 天内免租，超过 60 天按 1.5 元/立方米/天计费。
- 其他月份，月均日单量达到 3000 单时适用同一条款；不足 3000 单时沿用旧仓储分档。
- 旧仓储分档的内置价：≤30 天免费、31–120 天 2 元、121–180 天 3.5 元、181 天及以上 5.1 元。报价表可调整这些旧档位，不得覆盖 60 天免租及超过 60 天 1.5 元的新条款。
- 规则使用账单计费月份，不使用运行电脑的当前月份。
- `Total CBM within period` 仅保留为账单对照及体积差额，不作为金额核算基数。缺失尺寸或数量的行须标记异常，不能静默按零计费。

### 出库操作费与包材

月均日单量按账单出库订单去重数除以对应月份天数计算；首票价含 3 件。

| 月均日单量 | 首票价（含 3 件） | 第 4–19 件续件价 |
| --- | --- | --- |
| ≤500 | 旧报价，内置 1.8 元 | 旧报价，内置 0.6 元/件 |
| >500 且 ≤1000 | 旧报价，内置 1.7 元 | 旧报价，内置 0.6 元/件 |
| >1000 且 ≤2000 | 旧报价，内置 1.5 元 | 旧报价，内置 0.6 元/件 |
| >2000 且 ≤3000 | 1.4 元 | 0.5 元/件 |
| >3000 且 ≤5000 | 1.3 元 | 0.5 元/件 |
| >5000 | 1.2 元 | 0.5 元/件 |

从第 20 件起，仅超出的这一部分按 0.3 元/件，前 19 件仍按对应首票与续件价计算。以正数件数 `Q` 表示：

```text
操作费 = 首票价 + max(min(Q, 19) - 3, 0) × 续件价 + max(Q - 19, 0) × 0.3
```

例如日均 2500 单：19 件为 `1.4 + 16×0.5 = 9.4` 元，20 件为 `9.4 + 0.3 = 9.7` 元；不能把整单 20 件全部乘以 0.3。包材费用另计，继续按旧报价中的包材与 ABF 映射核对。

### 退件、退仓及装卸

- 退件处理费按订单退回总数量计算：2 元/单含 3 件，超过 3 件每多一件加 1 元。不能按每行 SKU 重复收取首票费。
- 退仓费：1.1 元/件。
- 装卸费：27 元/方，方数向上取整，例如 1.01 方计 2 方、54 元。
- 新增操作费档位、20 件起的分段价、退件新条款、退仓价与装卸价优先于旧报价；未覆盖或无法核实的杂费仍保留待确认。

## 账单与报价校验

账单包含 Invoice、仓储费、卸货费、出库+耗材、退件上架费、杂费六类工作表。服务先按名称识别；使用旧模板的位置回退时须给出提示，不能把同一子表重复当作多个费用表而继续核算。仓储费预览识别长、宽、高、数量列及实际表头；无法确认列含义时应提示修正模板，不能仅因固定列位存在便当作有效数据。

仓储费支持原英文尺寸列与中文“长/宽/高/数量”列，在前 20 行中识别实际表头并跳过前置标题；预览和正式核算使用同一套列识别。出库明细含多个自然月时提示按月拆分，不将多个账期的订单合并成错误的日均量。

缺少账单 Total CBM 时可以继续按实际体积核对，但体积差额留空并提示。缺尺寸、数量或必要日期的行需在结果中保留异常说明。

有订单但缺少有效交接日期时，在扫描阶段拒绝核算日均单量。退件同一订单任一行数量缺失、非法或为负时，整组费用留空并标记待确认；正常数值 0 不等于缺失。汇总核对金额仅累计可核算部分，须结合异常与待确认数查看，不能将未知行视为免费。`Is Return` 未标记为 `Y` 时不能显示正常。

报价解析按费率表头、费用分组、日均档位和包材代码定位。旧模板中仓储旧档为 `I5:I8`，操作费位于 `I9:I11/J9`，包材位于 `I43:I54/K43:K54`；2026-09 新模板新增仓储行，操作费移至 `I11:I16`、常规续件 `J11:J16`、第20件起续件 `K11:K16`，ABF 费率/代码移至 `I48:I59/L48:L59`。识别到新模板后不回退旧坐标，避免读错费率。ABF代码必须唯一且费率有效，不能从说明文字中抽取数字作为价格。

新模板 `G14:G16` 写着含4、5、6件；用户在2026-10-21明确确认仍按既定口径，所有档位均含3件。这三处差异仅作观测记录，不覆盖确认规则。旧模板中的退件、装卸值同样不覆盖新条款。

旧报价中的明确“免费/free”值按 0 识别；费率说明文字不从中提取数字当作价格，无法确认的费率直接报错。

## 参数与输出

| 参数 | 含义 |
| --- | --- |
| `input_file` | 必填，账单 Excel 路径 |
| `quote_file` | 可选，旧模板报价 Excel 路径 |
| `output_dir` | 必填，结果保存目录；成功提交参数后更新平台输出目录 |
| `account_id` | 所选平台马帮账号，账号密码由桥接注入 |
| `base_url` | 马帮私域 origin，默认 `https://900853.private.mabangerp.com` |
| `timeout_seconds` | 单次 HTTP 超时，默认 60 秒，范围 5–600 |
| `order_batch_size` | 批量查询条数，默认 1000，上限 1000 |
| `max_workers` | 回查并发数，默认 2，范围 1–8 |
| `verify_ssl` | 默认开启证书校验 |
| `sample_outbound_orders` / `sample_return_trackings` | 服务调试采样数，0 表示全部；页面不默认启用采样 |

输出文件为 `原账单名_核对结果.xlsx`，已存在时追加 `_2`、`_3`，保留历史结果。结果包含以下工作表：

| 工作表 | 内容 |
| --- | --- |
| 仓储费核对 | 原始列、核对数量、实际体积、账单 Total CBM、体积/库龄/单价/金额差额、异常说明 |
| 卸货费核对 | 方数向上取整后按 27 元/方核对 |
| 出库耗材核对 | 马帮订单匹配、件数核对、操作费、包材费与差额 |
| 退件上架费核对 | 按订单与 SKU 匹配退货记录，按整单退件数量计算费用 |
| 杂费核对 | 退仓等已覆盖费用及待确认项目 |
| 汇总 | 五项账单金额、核对金额、差额、异常数及辅助统计 |

页面保留仓储账单金额、实际体积核对金额、体积差额和结果路径，另展示五项费用汇总。账号密码不写入任务上下文或结果表。
