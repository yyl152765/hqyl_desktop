# 寰球云联自动化平台 0.2.56 发布说明

发布日期：2026-09-11。升级版本：0.2.55 → 0.2.56。

## 取消广告充值分档规则

按用户要求，越南、印尼自动充值不再使用日消耗分档阈值、分档周/月额度或是否提档判断。

- 删除分档源表读取、阈值完整性/递增检查及I/J的LOOKUP引用检查。
- 分档辅助列为空、报错、手填或修改，均不再成为充值拦截条件。
- 程序只按经过验证的七天消耗、余额和十天预算决定是否需要充值，不再要求配置越南或印尼的分档区间。
- 线上表格清除I/J/M的分档公式和对应源分档表，保留物理列位置；K/L的现有店铺额度记录保留。

## 保留的金额校验

继续保留0.2.55的严格币种与整数金额解析、GMT+7前七个完整自然日统计、成功报表与页面金额一致性、写入读回核验、同店执行锁、支付金额两次确认及审计证据。

十天预算仍为七天消耗÷7×10，越南按百位、印尼按万位取整；待充值金额按预算减余额计算并按万位取整。人工O列充值金额继续保留，自动模式仍需明确审核。

“待核验”仅表示金额、日期、采集证据、人工覆盖等尚未通过核验。此次移除分档不会把历史记录直接当作新采集；新版取得有效快照后会刷新为“需充值”或“无需充值”。线上原记录的状态说明会保留原有支付日志并补充具体原因。

## 升级

正常结束正在执行的任务并退出旧版后，安装`HQYLAutomationSetup_0.2.56.exe`，从新快捷方式启动并确认版本。0.2.55仍含分档检查，应升级到0.2.56；源码更新不会自动改变已经运行的进程。所有参与该流程的桌面和独立执行服务都需使用新的共享实现。

本次维护不执行实际充值，不改变平台自身的付款约束，不发布服务器更新源。

验证和线上备份位于`outputs/vn_id_ads_tiers_removed_20260911/`。0.2.55发布说明中关于必须补齐分档阈值才能放行的要求，自0.2.56起取消。
