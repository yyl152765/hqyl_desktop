# 0.2.87 本地修复候选包

本版修复 Lazada 余额统计中 Ads 已读取到金额，但截图因可见性检查失败而无法保存的问题。反馈店铺实测遇到新版“激活全站推广”弹窗，旧流程未识别其关闭按钮。本版补充该弹窗组件的识别；已确认且唯一的关闭按钮位于画面外时，先滚动到按钮，再重新核验和原生点击。未知弹窗仍不自动关闭。

同时修复隐藏的广告余额副本、金额文字外层过宽空白区域导致的误判，不再要求整块空白区域完整进入画面。

现在以实际显示的余额标签、币种和金额文字的位置核对可见性；需要时只滚动页面，让目标文字进入画面。截图前后继续核对店铺页面身份、金额与币种，避免保存变化中的页面。流程不修改财务文字，不清除未知遮罩；存在多个真实可见候选、页面身份不明或金额被遮挡时仍停止采集并报告原因。

0.2.86 的紫鸟 V6 启动准备、所选客户端进程清理、自动化端口归属核验、驱动自动下载与修复、V6 安装检测和官方下载入口继续保留。驱动及启动相关源码按上一版本哈希核对，本轮复用已经封存的验证证据，不宣称重新执行了官方驱动下载或真实客户端重启测试。

Excel 继续只有一张“余额统计”表，依次排列店铺名称、Income、Income截图、Balance、Balance截图、Ads、Ads截图、processing、processing截图，再接站点等信息。截图列只放图片，保持缩小显示并保留原图；没有处理中提现时也保留 processing 状态截图。完整 Balance 截图、动态尺寸重拍、失败店铺重试及已有账单流程均保留。

本轮测试重点为 Ads 弹窗关闭、可见性、余额采集与发布契约。0.2.86 的完整回归结果作为单独基线记录，不与本轮测试数相加。反馈店铺 TH005 通过紫鸟 CLI 进入 Ads，确认新版弹窗，关闭后取得显示“泰铢 -3.52”的页面截图，截图前后金额和可见性检查一致；TH006 仍遇到代理连接失败。此验证不包含安装包的原生窗口身份验收或客户电脑端到端运行，测试店铺均已正常关闭。最终验证结果以同版本 `BUILD_MANIFEST` 和 `PACKAGE_VERIFICATION` 为准。

本次为本地修复打包，未同步桌面上游、未改写父仓库远端、未产生上游合并提交，旧 0.2.86 产物保留。当前工作区含既有修改，安装包未签名，因此作为本地内部验收候选交付；尚未安装到客户电脑、上传或部署。
