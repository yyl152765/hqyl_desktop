# 寰球云联自动化平台 0.2.34 发布说明

## 马帮收支报表

1. 新增独立的“马帮收支报表”页面，使用平台已绑定的马帮账号运行。
2. 迁移旧流程中的 21 个店铺自定义分类，并新增印尼、菲律宾、马来 3 个雅仓海外仓分类。
3. 查询条件统一使用发货时间，付款时间、创建时间、结算时间等其他日期条件保持为空。
4. 每个分类独立生成 CSV，并保存到用户设置的本地输出目录；空结果也生成带表头的 CSV。
5. 新流程不读取共享盘中的表单快照，不发送钉钉文件，也不修改旧的 `mabang_process` 流程。
