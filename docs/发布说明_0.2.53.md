# 寰球云联自动化平台 0.2.53 发布说明

发布日期：2026-09-11。升级版本：`0.2.52` → `0.2.53`。

## 更新内容

修复「TEMU 发货渠道更改」导入 Excel 时要求缓存日期必须为当天的问题。直接读取文件中已保存的长、宽、高和重量，不再因旧日期、未来日期、日期缓存缺失或日期公式无法识别而拒绝导入。

日期信息仅作为记录；长宽高、重量的数值检查及公式结果读取仍正常执行。仅按顺序处理已开启（ON）的渠道，关闭（OFF）渠道跳过且不占用 Excel 行。

## 使用方式

升级后重新选择原来的 Excel 文件并读取，无需为了日期变化重新计算或保存文件。程序使用表格中已保存的数值，保留顺序，不修改原文件。

## 发布及部署

- `HQYLAutomationSetup_0.2.53.exe`：客户端安装程序。
- `HQYLAutomation_ServerUpload_0.2.53.zip`：服务器上传包，含安装程序、更新清单、SHA-256、构建清单和部署脚本。
- `HQYLAutomation_0.2.53.zip`：客户端分发包。

将服务器上传包复制到服务器并解压，运行 `部署更新源.bat`。默认发布目录为 `C:\inetpub\wwwroot\hqyl`；如果站点目录不同，先修改 `deploy.ps1` 中的 `$SiteRoot`。脚本先复制并校验安装包，再更新 `latest.json`，保留旧清单备份。
