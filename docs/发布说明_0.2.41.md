# 寰球云联自动化平台 0.2.41 发布说明

发布日期：2026-08-26

## 新增 BS 商品ID查询

1. 支持批量输入 SKU，按首次输入顺序去重，单次最多查询 5000 个不同 SKU。
2. 固定使用 **Parent SKU / Fuzzy Search / Views 降序**，读取搜索结果第一条的 **Item ID**，不使用 BigSeller 内部商品 ID。
3. 当前查询范围为当前账号可访问的全部店铺中的 **Shopee 在售商品**；查询不触发商品或库存同步。
4. Excel 严格包含 `SKU`、`Item ID` 两列，均以文本保存，保留前导零和长数字，防止输入被解释为公式。未匹配或查询失败的 SKU 保留，Item ID 留空；页面和日志显示各自状态及原因。
5. 接入已有 BigSeller 账号管理及图形验证码配置，提供逐条进度、结果预览、打开 Excel 和输出目录、切换页面后恢复最近任务等功能。

## 使用说明

1. 安装或更新至 `0.2.41`，从工作台或侧栏 BigSeller → Shopee 商品 → **BS 商品ID查询**进入。
2. 在设置中绑定并选择 BigSeller 账号，配置已有图形验证码服务。发布包不附带用户账号、密码或登录会话，开发验收账号也不会自动绑定到客户端。
3. 粘贴 SKU，支持换行、英文/中文逗号和分号、Tab 分隔；选择输出目录后点击“开始查询并导出”。
4. 完成后检查命中、未匹配和失败数量，再打开 Excel。页面最多预览 500 行，导出文件包含全部输入结果。登录、权限或限流异常时，按页面提示处理后重试未完成 SKU。
