# 0.2.81 发布说明

日期：2026-10-26。

## 本次修复

泰国 Shopee 广告充值提交后，部分订单会进入独立的信用卡确认页。旧流程未处理该页的 Pay 按钮，导致用户仍需手动点击一次。

- P 卡及 WORLD 卡流程均接入信用卡确认页处理，兼容直接成功及延迟跳转。
- 仅处理本次订单所在窗口或新窗口，严格匹配 Shopee 支付网址，核对含税总额后只点击一次 Pay。
- 原始提交及二次确认均防止异常后重复点击；窗口上下文获取失败时停止提交。
- 成功提示限定为明确的支付结果，排除无关“成功”提示。未取得最终结果时保留“处理中”，避免误报失败后重复付款。

## 代码与依赖来源

权威桌面上游为 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main`；本次核对最新提交仍为 `39bf912453cf6a6e554779ef1deb7aff522b4af0`。本工作区属于父仓库 `hqyl_project`，父仓库提交单独记录在构建清单中。本次不创建 Git 合并提交，不向公开仓库推送。

以 0.2.80 已验证的共享依赖快照为基础，131 个 superbrowser 文件中仅更新 `implement/shopee/th_shopee_ads_recharge.py`，23 个 Mabang 文件保持原样。保留 KEC 报价、Excel TEXTAFTER、Lazada 账单、钉钉配置与店铺简称匹配等既有功能。个人支付记录、临时实测脚本、浏览器数据不纳入安装包。
