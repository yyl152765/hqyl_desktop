# 0.2.84 发布说明

日期：2026-10-29。

## Lazada 余额统计

- 四项金额与截图合并到唯一的「余额统计」工作表。列顺序为店铺名称、Income、Income截图、Balance、Balance截图、Ads、Ads截图、processing、processing截图，后面保留站点、币种、状态、采集时间和说明。
- 四张图片直接嵌入 Excel 的 C/E/G/I 列，每项金额后紧跟对应截图，截图单元格只放图片。展示尺寸按比例缩小至最大 320×200 像素，保留原始图片质量，单独发送 Excel 仍能显示。
- Balance 保存 100% 比例的完整页面长截图，包含总计余额、当前页全部提现记录和分页控件；另存带紫鸟标题的原生窗口图。不会拼接其他历史分页。
- 最新提现成功或确认无提现记录时，processing 金额仍留空，但必须保留状态截图。可复用已核验的 Balance 全页图；需要独立截图时会核对提现筛选、日期、记录和状态。缺图或图损坏不会标为采集成功，重试旧批次时会重新采集对应店铺。
- 截图前后校验金额、提现数据、页面和窗口身份，拒绝被遮挡或裁剪的图片；截图所需的临时页面布局调整会在完成或异常后恢复。
- 页面导航超时但已精确到达对应国家及资金页面时，继续既有语言、金额与截图验证；其他页面仍报错，不重复登录。店铺打开失败时保留失败阶段和异常类型。

提现状态与金额口径不变：已知处理中提现记录负数金额；最新提现成功或明确无记录时金额留空；无法确认的状态仍记录错误。详见 [余额统计使用说明](balance-statistics.md)。
