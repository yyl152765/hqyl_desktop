# 1.0.12：Shopee 印尼多月份下载与失败恢复

发布日期：2026-11-27。

- 月份支持范围选择和单独勾选。例如选择 1–6 月后，可以取消其中任意月份；每个店铺依次完成所选月份的收入账单、服务费账单和税票。
- 默认同时执行 5 家店铺，可调整为 1–5 家。每家店铺复用同一个窗口处理多个自然月，完成后关闭，再接续下一家；遇到账号认证失效或窗口关闭未确认时暂停后续调度。
- “重试失败”只处理失败或中断的店铺月份，已完成、无账单和平台缺税票的任务跳过。“补查税票”单独处理平台此前未提供税票的任务。旧单月批次可继续恢复，升级清单前保留备份。

本版本基于已发布的独立桌面提交 `bad6cfc9cf3ac7805032a5114ac0fa6d212cc74f`，保留 Lazada 受限账单流程、钉钉保存配置与操作人选择、国家店号唯一匹配，以及独立运行时的功能限制保护。权威上游为 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main`，发版准备时已实际 fetch，核对上游提交为 `b9d1a39ceefbba0aa47dc3968747f21482b1dce6`；本次是在已有发布提交之后追加改动，不是父工作区的 Git 合并。

验证记录：

- 独立发布源码的 571 项测试、651 项子用例通过，无失败、错误或跳过；分三批运行，每批进程树内存限制 1800 MiB。
- 实际 Edge 页面验证 1–6 月选择、取消 3 月、默认并发 5 和两个恢复按钮，未出现 JavaScript 页面错误。
- 正式 WebDriver 通过桌面任务入口完成 5 店 × 2 月，实测窗口峰值 5。重试分别跳过 4、8、9 个已处理月份；最终下载失败为 0，31 份文件重新通过账期、完整性和哈希校验，所有测试窗口关闭。
- 31 份文件包括 10 份收入 Excel、20 份 Master Invoice、1 份 Tax Invoice。10 个店铺月份仍存在平台未提供的部分税票，保留待补状态，不能视为税票全部齐全。CLI 实页核对月份与两份 PDF，哈希和 WebDriver 一致。
- 测试将收入报表生成等待缩短至 180 秒以验证恢复，正式默认值仍为 30 分钟。未执行全部店铺下载、冻结包连接实店或员工电脑安装；冻结包、安装包载荷、OSS 读回与免登录整包下载的验证结果见同版本构建清单及本地发布记录。

个人配置、店铺账号凭据、Cookie、签名下载地址、真实账单样本与内部人员映射不进入公开源码；发布沿用现有员工更新渠道和应用配置。更新方式为平台内检查更新，或访问现有员工安装包下载地址。
