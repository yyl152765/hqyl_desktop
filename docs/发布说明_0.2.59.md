# 寰球云联自动化平台 0.2.59 发布说明

构建日期：2026-09-17。调整 0.2.58 新增的 TEMU 在售商品导出登录方式。

## 使用方式

1. 在「设置 → 紫鸟账号」绑定公司、账号和密码，并选中本次运行账号；与广告充值使用同一账号管理。
2. 进入「紫鸟流程 → 在售商品导出」，核对自动发现的紫鸟客户端和驱动目录，也可手动选择。
3. 点击「刷新店铺」，程序使用所选账号登录紫鸟自动化客户端并获取店铺列表。
4. 粘贴完整店铺名或勾选候选店铺，匹配预览，选择输出目录并开始导出。

不再要求用户单独安装、授权 ziniao-cli 或填写 API Key、终端识别码。客户端未开启自动化模式时会尝试启动；如果普通模式客户端占用，页面会提示先结束其他流程并退出普通模式后再刷新。

## 本次修正

- 前端只传账号 ID，后台从平台配置读取公司、用户名和密码，不接受前端覆盖凭据。
- 账号切换后清空旧店铺候选及预览；延迟返回的旧账号请求不能覆盖新账号页面。
- 批次记录按账号身份隔离，禁止跨账号查看、恢复和重试。任务运行中固定最初选择的账号。
- 与广告充值复用紫鸟自动化客户端和驱动能力，验证店铺身份、代理 IP 和卖家身份后导出。
- 固定同时只处理一家店，成功或失败后都关闭当前店铺并确认端口已退出，再打开下一家；关闭失败则暂停后续店铺。
- 原始文件归档、在售中筛选、全部价格状态、零库存及隐藏行保留、汇总和失败重试规则延续。

0.2.58 的 CLI 批次文件保留，不自动转换为平台账号批次。使用新版需重新选店导出；请使用 0.2.59 安装包替代 0.2.58。

## 验证范围

账号注入、登录错误脱敏、账号隔离、浏览器连接清理、页面交互和工作簿逻辑通过本地测试；最终检查数量及包内核对结果见 Build Manifest。

平台账号已绑定。当前普通模式紫鸟客户端占用，需重启切换到自动化模式后继续实测；新登录通道的实机验证尚未完成。此前两店共 15,310 行导出属于 0.2.58 CLI 通道的历史结果，不作为本版登录通道验收。本版继续保留试运行标记。

本地构建候选，源码含未提交修改且未签名。本次不执行更新源发布。安装前正常结束任务并退出旧版，安装后确认版本为 0.2.59；必要时退出新版并重新安装保留的旧版，保留用户配置及导出目录。
