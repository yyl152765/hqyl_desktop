# UI 选型与改造说明

## 1. 查看的方向

当前项目是内部桌面工具，不适合做营销站或大面积装饰风格。更适合采用企业中后台的设计语言。

调研方向：

- TDesign Vue Next：腾讯开源的 Vue 3 企业级桌面端组件库，适合中文中后台。
- TDesign Vue Next Starter：基于 Vue 3、Vite、Pinia、TypeScript 的中后台项目模板。
- shadcn-admin：React + Vite + shadcn/ui 的现代后台模板，视觉更轻，适合内部工具。
- Ant Design Pro：成熟完整，但项目体量偏重。

## 2. 当前选择

当前版本使用静态多页面 H5，不马上引入 Vue/React，原因：

- 现阶段重点是验证桌面壳、后端任务、打包和更新链路。
- 每个流程使用独立 HTML 和独立业务脚本，页面按需加载，静态页面维护成本较低。
- 导航、账号与后台任务恢复由共享脚本统一提供，避免模块互相影响。
- 后续如果工具数量增多，`frontend` 可以平滑替换成 Vue 3 + TDesign。

## 3. 当前 UI 改造原则

- 品牌从 `Mabang Desktop` 改为 `寰球云联自动化平台`。
- 左侧导航按平台能力组织：流程驾驶舱、马帮流程、紫鸟流程、更新中心。
- 主区域采用中后台布局：状态指标、参数表单、运行日志、更新中心。
- 颜色控制在中性灰、蓝、绿色、琥珀色，避免单一色系。
- 保留 8px 以下圆角，减少装饰，突出表单和任务执行效率。

## 4. 后续建议

当迁移到 5 个以上工具时，建议将 `frontend` 升级为：

```text
Vue 3 + Vite + TypeScript + TDesign Vue Next
```

原因：

- 中文中后台组件完整。
- 表格、表单、弹窗、抽屉、步骤条、日期选择器都可直接复用。
- 后续接入马帮、紫鸟、BigSeller、店小秘等模块时，统一 UI 成本更低。
