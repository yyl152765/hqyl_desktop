# 寰球云联自动化平台 0.2.29 发布说明

## 马帮仓库权限识别与补齐

1. 将“查看商品”和“查看仓库”拆成两组独立状态，不再使用统一的“仓库已添加”判断。
2. 只有 `stockWarehouse[]` 与 `allocationwarehouseAssistant[]` 都包含目标仓库时，员工才会显示“无需新增”。
3. 只有查看商品时，预览显示“查看仓库缺 N 个”；只有查看仓库时，预览显示“查看商品缺 N 个”。
4. 保存请求对两组字段分别做并集合并，保存后重新读取并分别校验，任意一侧未生效都会任务失败。
5. “查看全部仓库”模式保持原值，只补目标复选框，不缩小员工已有权限。
6. 结果表新增独立的“查看商品”和“查看仓库”列，并更新资源版本标识，避免客户端继续使用缓存脚本。
