# 0.2.73 发布说明

日期：2026-10-15。

本次同步独立公开仓库 `yyl152765/hqyl_desktop` 最新 main 提交 `33b4d9f3`（Add local Excel discount filtering and batch export tool），新增本地 Excel 折扣筛选批量导出工具。新工具纯本地运行、不需要账号和绑定，可批量导入最多 100 份 `.xlsx` / `.xlsm`，按最低折扣率筛选并导出结果表、审核明细以及 ZIP 包；同时保留 0.2.72 的 BigSeller 限流识别与请求节流修复，以及之前的 Lazada、马帮、紫鸟等流程。

## 新增内容

- 工具入口：侧栏新增「通用工具」分组下的 `Excel 折扣筛选`，Dashboard 同步新增「通用工具」选项卡与对应的图标 + 卡片。开发入口：`python desktop_entry.py --page=lazada-campaign-workbook`。
- 流程能力：
  - 导入最多 100 份 `.xlsx` / `.xlsm`，空白模板可单独导出，源文件不修改。
  - 识别列「原价」「活动价」「推荐价」；模式有 `auto`（自动识别）、`plain`（按已有活动价筛选）、`invited`（按推荐价填充活动价后筛选）。
  - 阈值默认 0.95（最低折扣率），按活动价 / 填写后活动价计算折扣率并保留不低于阈值的行。
  - 输出：结果表（修改后列表与保留新行的原行）、审核明细（每行的命中模式、行数、未解析行数）、ZIP 包（按源文件名组织），另存到用户选择的输出目录，不覆盖源文件。
- 桥接层：`backend/app_bridge.py` 新增 `lazada_campaign_workbook` 工具注册和 `get_lazada_campaign_workbook_info` / `choose_lazada_campaign_files` / `inspect_lazada_campaign_files` / `export_lazada_campaign_template` / `start_lazada_campaign_workbook` 等 5 个方法；侧栏、Dashboard、launcher 和前端完整性测试同步调整。
- 服务层：`backend/services/lazada_campaign_workbook.py` 完整实现检查、模板导出、按模式折扣筛选、压缩和审计明细生成；最大文件数限制、阈值解析、Sheet 名识别和结果落盘规则均按上游 `33b4d9f3` 实现。
