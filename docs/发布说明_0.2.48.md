发布日期：2026-09-03

## 新增马帮批量添加开发员

1. 新增 **马帮通用工具 → 批量添加开发员**入口，支持一行输入一个完整员工显示姓名，按输入顺序去重，单次最多处理 100 名员工。
2. 先执行「预览检查」，精确匹配员工并展示已有岗位、商品查看方式及待执行操作，确认后点击「批量保存」。
3. 保留员工原有岗位并追加「开发员」，将「查看商品 → 库存 SKU」设为「按商品父目录查看」（模式值 `1`）。保留商品父目录原有勾选项，以及仓库、角色、部门等其他权限。
4. 只保存唯一精确匹配且正常启用的员工。同名、未找到、停用、关键控件缺失的员工不提交修改；保存前再次读取，权限与预览不一致时要求重新预览。
5. 已满足目标的员工跳过。每次保存后回读核验目标字段和原有受保护字段，逐员工展示处理结果；写请求失败或结果不明确时不自动重试提交。

## 使用说明

1. 安装或更新至 `0.2.48`，进入 **马帮通用工具 → 批量添加开发员**。
2. 选择已绑定的马帮账号，一行输入一个与员工列表完全一致的显示姓名。
3. 点击「预览检查」，核对匹配员工和待执行修改。账号或名单变化后需要重新预览。
4. 点击「批量保存」，完成后检查每名员工的保存及回读结果。若提示保存结果未确认，先检查该员工当前状态，再重新预览处理。
