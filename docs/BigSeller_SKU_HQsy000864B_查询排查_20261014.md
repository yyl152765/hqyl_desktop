## 可以确认的问题与证据边界

原代码在商品列表返回未识别的非零业务错误码时，统一显示“BigSeller 商品查询接口返回失败，请检查账号权限或稍后重试”，不保留错误码。截图正是这条提示。它表示请求没有成功，不能作为“SKU 没有商品”的证据，也不能据此确认账号权限不足。

BS 商品 ID 查询连续发送成功请求，没有对标模块已有的 0.75 秒请求间隔；业务层限流只有错误码恰好为 429 时才会被该模块识别。这是批量查询可能失败的一个风险，但本次实测未捕获失败响应，不能把截图历史失败确定归因于限流。

当前账号和该 SKU 的正常查询已验证。没有取得原运行的服务端错误码或完整历史日志，因此当时究竟是限流、临时服务异常还是其他业务错误仍不能确认。
