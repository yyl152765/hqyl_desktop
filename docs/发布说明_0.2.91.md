# 0.2.91 TEMU 对账中心加载等待修复

TEMU 先显示店名、后加载财务查询表单时，旧流程会提前操作侧栏。本版在指定对账页面等待卖家身份和查询表单同时就绪，然后设置日期、生成列表及账务详情并下载全球明细。等待期间仍检查店铺身份、登录状态和人工验证，超时给出明确的表单未加载提示。

保留 0.2.90 的店名异步加载和重复店名兼容、同名 sheet 汇总及每行紫鸟店铺名；已有 Lazada、SKU 和钉钉功能不变。安装后重启客户端生效，更新仍由用户手动选择。

新增浏览器回归覆盖店名先出现、查询表单延后出现且没有加载指示器的场景，确认等待期间不点击侧栏；覆盖等待超时与加载期间身份变化。发布验证及实店导出证据另存本地发布清单，店铺数据不提交到公开仓库。

兼容全球下载确认页的两种界面：保留账号信息共享勾选框的界面，以及只有共享说明和确认按钮的界面。只处理本次下载新开的同一店铺全球财务页面，不修改「今日不再提醒」偏好；缺少共享说明、身份不符或控件重复时仍停止。
