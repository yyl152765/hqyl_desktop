# 发布说明 0.2.18

发布日期：2026-07-23

## 本次变更

- 修复 EchoTik 商品达人采集运行到后段后持续收到 HTTP 200 HTML 错误页、导致剩余商品连续失败的问题。
- 默认启用低请求模式，使用商品列表数据生成商品结果，不再逐商品请求详情接口；需要详情时仍可通过后端参数显式开启。
- 每轮请求达到安全阈值前自动冷却并重建登录会话；网络错误、限流、服务端错误及 HTML 错误页采用有限退避重试。
- EchoTik 连续返回 HTML 错误页时触发熔断，停止继续请求并生成包含已采结果和未采状态的 Excel。
- 达人分页结果发生轻微变动时保留已稳定取得的数据，并在商品错误列记录缺失数量，不再整批丢弃。
- EchoTik 浏览器探测脚本改用环境变量读取账号密码，不再保存明文凭据。
