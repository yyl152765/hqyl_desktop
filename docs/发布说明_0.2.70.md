# 0.2.70 发布说明

本次发布把独立仓库 `yyl152765/hqyl_desktop` 最新 `main`（提交 `18ee6535`）上的两个 Lazada 模块合并进本仓库并重新打包，两个模块功能完整可用：

- **泰国 Lazada 广告数据**：按指定日期（**默认采集昨天**）采集各店铺广告费与业绩，写入指定钉钉 Sheet，并保留本地结果文件。
- **Lazada 后台收支数据**：支持**泰国、菲律宾、马来、印尼、越南**五国，按账单区间采集**总金额、收入、扣减项**写入 `B:D`，并按国家与区间保存截图；钉钉 `F` 列图片通过 `dws` 同步。

合并同时带入了两项底层修复：钉钉接口对 503、限流等临时错误自动重试（最多 5 次，退避 1/2/4/8 秒）；Lazada 开店等待逻辑同时识别跨境 GSP 与本土卖家中心页面。

保留 0.2.69 的广告充值内置数据库连接与启动只读校验，以及 Product Ads 报表、印尼 Saldo Iklan 识别、新品认领时间查询等既有功能。

产物为本地 Windows 安装包和服务器上传包；不上传、不安装，不执行真实采集或写入在线表格。构建来自带既存未提交改动的工作区，候选包未数字签名。账号、Cookie、钉钉及邮箱凭据继续排除在发布包外。

验证结果：370 项回归测试通过（packaging 86 + 181 subtests、Lazada 广告 77 + 51 subtests、Lazada 账单 207 + 87 subtests），0 失败 0 错误 0 跳过；打包产物 `--self-check` 启动自检通过（ADS 数据库内置凭证校验 passed）；两个模块的后端模块与前端页面均已确认进入冻结包；两个 ZIP 的 CRC 与成员清单校验通过；`deploy.ps1` 语法检查通过。
