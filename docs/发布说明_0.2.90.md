# 0.2.90 TEMU 财务导出身份等待修复

修复 0.2.89 在进入对账中心后，店名尚未加载便报告“无法唯一确认当前 TEMU 卖家身份”的问题。

实际页面会先显示一个可见但内容为空的店名容器，再加载店名或跳转到登录页。旧判断只检查容器数量，提前进入了身份校验。本版等待真实店名出现后再核对所选店铺；同一店名的重复元素合并识别，不同店名或店铺不匹配仍拒绝导出。

身份等待期间遇到页面跳转导致的读取中断，会在原有超时范围内重读，不重新导航或重复提交导出。若跳转到登录页，会明确提示先登录该店铺；一直未加载出店名时，会说明加载超时。

回归覆盖延迟加载店名、空容器跳转登录页、重复店名、错误店铺、读取中断及超时，并保留原有全球财务明细、表头与汇总校验。此前两店 CLI 下载验收作为既有基线，不计作本次完整无人值守验收；实际测试和安装包校验以同版本构建清单为准。

本版保留 0.2.89 的业务功能、内部依赖和用户配置。安装 0.2.90 并重启客户端后修复才会生效。更新继续由用户手动选择，旧安装包保留，不自动上传更新服务器。
