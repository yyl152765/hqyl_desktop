# 寰球云联自动化平台 0.2.28 发布说明

## 修复内容

1. 修复 Shopee 广告充值选择 `WORLD` 时仍可能使用默认 `PAYONEER` 卡的问题。
   - 本次任务的卡类型会显式传入支付页选卡流程。
   - WORLD 卡点击后必须读取到目标卡自身的选中状态才允许提交支付。
   - 页面无法确认 WORLD 卡已选中时，任务会停止并报错，避免使用错误银行卡付款。
2. 修复马帮仓库权限批量开通只勾选“查看商品”、未勾选“查看仓库”的问题。
   - “查看商品”写入 `stockWarehouse[]`。
   - “查看仓库”写入 `allocationwarehouseAssistant[]`，并保持 `see_warehouse=1`。
   - `warehouseAssistant[]` 属于“查看订单”权限，升级后保持原值，不再被误改。
   - 保存后重新读取并分别校验“查看商品”和“查看仓库”的目标仓库。

## 验证结果

- 自动化测试：294 项全部通过。
- 马帮线上权限页只读核对：已确认目标仓库在旧版本中仅写入“查看商品”，新字段映射与页面 DOM 一致。
- WORLD 选卡回归测试：已覆盖显式卡类型传递和选中状态无法确认时禁止付款。
