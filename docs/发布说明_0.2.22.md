# 发布说明 0.2.22

发布日期：2026-07-24

## EchoTik 类目筛选修复

- 修复选择二级商品类目（例如“猫狗配件”）时，接口传递单个子类目 ID 导致返回 0 条的问题。
- 按 EchoTik 真实接口要求传递完整类目路径和 `product_categories[]` 参数，例如 `[602118, 818696]`。
- 支持同时选择多个类目路径，分别查询后去重合并，再按商品指标稳定排序。
- 保留原有无关键词采集、商品数量上限和本地筛选逻辑。

## 验证结果

- 真实 EchoTik 验证：猫狗配件路径第一页返回 50 条；设置上限 75 时取得 75 个唯一商品，0 条跑出类目。
- EchoTik、前端完整性和版本一致性专项测试：38 项通过。
- 完整自动化测试：270 项通过。
- 前端 JavaScript 语法检查、Python 编译检查和 Git 差异检查通过。
