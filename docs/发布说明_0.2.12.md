# 发布说明 0.2.12

发布日期：2026-07-10

## 本次变更

- Shopee 马来和泰国广告充值支持 WORLD 卡类型。
- WORLD 支付统一延长支付结果等待时间，并兼容直接进入验证码输入页的支付流程。
- 自定义充值成功后，在线表格按店铺和充值金额匹配已有记录；未找到时自动新增完整充值记录。
- 失败充值不登记到在线表格。
