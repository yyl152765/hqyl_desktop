# 寰球云联自动化平台 0.2.60 发布说明

修复 TEMU 在售商品导出填写店名后无法直接运行的问题。旧界面的“刷新店铺 → 匹配预览”前置步骤会使开始按钮持续禁用；新版取消勾选店铺、选择方式、刷新和预览按钮。

## 使用方式

1. 确认「设置 → 紫鸟账号」中已绑定并选中运行账号。
2. 每行填写一个紫鸟完整店铺名，填写输出目录。
3. 点击「开始导出」。后台自动登录、读取当前账号的店铺、按名称匹配并创建批次，按填写顺序逐店执行，重复名称和空行自动忽略。

客户端路径和驱动目录继续自动发现，也可手动选择。输入名称和输出目录后即可开始，无需手动刷新或预览。名称不存在、重名、平台不符、客户端登录失败等情况会直接显示原因；处理后可再次点击开始。

同时只打开一家店铺：当前店铺完成或失败后，确认关闭再打开下一家；关闭失败暂停后续店铺。已完成批次的原始文件、汇总及失败重试继续保留，账号之间不能混用。

## 验证与范围

本地浏览器交互测试覆盖填写即运行、修改名称后运行、失败提示及再次启动、账号切换和失败重试；另通过真实桌面后台入口与模拟紫鸟接口联测，确认无需先刷新或生成预览即可创建正确的批次。测试不调用真实店铺。

源代码测试、成品自检、包内代码与资源比对和 ZIP 校验结果见本版 Build Manifest。新账号登录通道的实机导出仍需切换普通模式紫鸟客户端后验证，历史 CLI 导出结果不作为本版登录验收。

本地未签名候选包，源码含未提交修改。本次仅打包，未上传更新源。退出旧版后安装 0.2.60；0.2.59 安装包和用户配置、导出文件保留。
