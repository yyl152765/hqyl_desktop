# 寰球云联自动化平台 0.2.32 发布说明

## 菲律宾各组商品销量报表

1. 修复马帮“平均单天销量”改按自然月天数计算后，自定义日期区间报表被误判为日期口径异常的问题。
2. “平均单天销量”改为根据马帮返回的“销售数量”和用户所选日期区间在本地重新计算。
3. `2026-07-01` 至 `2026-07-30` 按 30 天计算：销售数量 `3421` 的日均销量为 `114.03`；31 天区间为 `110.35`。
4. 移除无效的分页兜底逻辑，避免相同口径异常导致二次请求和长时间等待。
5. 增加销售数量列、数字格式和统计天数校验，防止源 CSV 格式变化时静默生成错误数据。
