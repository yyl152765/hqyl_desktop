# TEMU / Lazada 余额统计

两个模块读取运行时页面金额，并生成 Excel、原始窗口截图及 `manifest.json` 批次清单。TEMU 待结算金额按用户所选订单创建月份筛选，默认上一个自然月；当前账户余额不回溯到该月月末。

## 使用

1. 选择已绑定且有目标店铺权限的紫鸟账号。
2. 输入完整店铺名称，每行一个，选择输出目录。TEMU 选择月份；Lazada 可自动识别站点，或限制为指定站点。
3. 启动采集。每家店铺依次打开、读取和关闭；若无法确认上一窗口关闭，后续店铺暂停执行。
4. 完成后查看 Excel 和每店状态。金额为空且附有错误说明表示尚未取得可靠数据，不能作为 0 使用。
5. 对部分完成或失败的批次选择重试。必须使用原紫鸟账号；原月份和站点范围保持不变。健康的成功行会复用，失败行或截图丢失、损坏的行重新采集。

店铺名只接受完整匹配或规范化后的完整匹配，不进行包含式、模糊猜测。平台信息、唯一店铺 ID、重试账号身份均需核对。

## 金额口径

| 平台 | Excel 字段 | 口径 |
| --- | --- | --- |
| TEMU | 平台 | 固定为 `temu` |
| TEMU | 店铺 | 紫鸟完整店铺名 |
| TEMU | 账户总金额 | 资金页面当前账户总金额 |
| TEMU | 预估待结算销售额 | 结算页面按所选订单创建月份筛选后的待处理款项 |
| Lazada | income | 我的收入→收入概况→待释放 |
| Lazada | Balance | 我的余额→总计余额（印尼菜单名称为我的钱包）；只有明确确认跨境店余额不可用时按流程填 0 |
| Lazada | Ads | 超级推广→平台内解决方案→总览→我的账户→可用余额 |
| Lazada | processing | 余额流水中按交易时间最新一笔提现，已知非成功状态填负数金额；最新提现成功或确认无提现记录时留空 |

未知提现状态、页面错误、无法确认的金额和筛选失败均记录错误，不自动归零。跨境余额填 0、成功提现或无记录留空的分支会在清单中保存明确的 `evidence_exemptions` 原因，并按流程不插入对应截图。

金额保留正负数、零与空白之间的区别。表格保留站点和币种，不进行跨币种求和。Lazada 目标站点为 PH、MY、TH、ID、VN、SG；TEMU 的全球账户可记录 `GLOBAL` 和页面实际币种，例如 USD。

## 导出与截图

TEMU 首五列依次为平台、店铺、账户总金额、预估待结算销售额、截图，两项原图分别置于 E/F 列。Lazada 汇总表首五列为店铺名称、income、Balance、Ads、processing，证据分别位于 `Income截图`、`Balance截图`、`Ads截图`、`processing` 工作表。

每张截图上方的 Excel 单元格显示完整店铺名和采集时间，明确标注“采集记录（软件附注，非截图原文）”。这些内容是工作簿文字，不修改、不覆盖原始 PNG。原图保持浏览器边框及页面原貌，缩放展示时保持比例，文件仍保留在批次 `evidence` 目录。

原生截图按完整窗口标题、紫鸟进程及窗口身份核对；最小化窗口、空白页面、采集中发生的身份、URL、尺寸、位置或显示状态变化均拒绝作为证据。紫鸟地址栏内的店铺标签可能自动省略文字，完整窗口标题匹配不代表截图上的标签一定完整可见，因此应同时查看旁边的采集记录。

Excel 和批次清单采用临时文件写入后替换。导出不会写入账号密码，批次只保存账号身份摘要；源页面 URL 不保存查询参数和片段。

## 验证范围与已知限制

截至 2026-09-28，181 项定向测试通过，覆盖月份跨年、店铺歧义、平台核对、失败清理、账号隔离重试、金额空值/负数、截图豁免、截图损坏恢复、原始图片嵌入及原生窗口身份/尺寸变化防护。

提现检查保留余额流水页面默认的约 180 天范围，核对起止日期和第 1 页倒序后再判断。范围被缩小时拒绝取数。“无提现记录”仅指该范围；本次泰国样本为 2026-03-28 至 2026-09-28，不代表全部历史没有提现。

本地 Windows 的原生窗口截图已成功验证，能够记录浏览器边框和正常渲染的页面。945 像素宽和 1936 像素宽窗口中，紫鸟的店铺标签均可能被截断。截图前后检查目标页面确实是可见页签，避免把其他登录标签页截为财务证据。

2026-09-28 使用已登录的普通紫鸟客户端，经仅用于本机验证的 CLI/Selenium 适配器执行实际 `collect_temu_balance`，完整跑通指定店铺「袁晶-菲律宾021-和韌-herefn」：订单创建时间 2026-08-01 至 2026-08-31、待处理款项 0.00 USD、当前总金额 3379.71 USD，导出两张真实页面截图及 Excel。这些值是当次快照，后续可能变化。正式桌面应用仍使用已有账号绑定的 Selenium 自动化运行时；此次未重启紫鸟切换运行模式。

真实财务页面兼容性需分别记录站点、账号页面版本、字段和筛选结果。不能用模拟测试通过或某一站点通过代替全部站点验收。TEMU 全球账户与区域账户的资金入口、结算界面及筛选控件可能不同；Lazada 的本地/跨境账户和提现状态显示也需按实际页面验证。

Lazada 已在菲律宾、马来西亚、泰国、印尼、越南选择 1–2 家可登录店铺验证；马来西亚同时覆盖本土店和跨境店。当前紫鸟账号没有新加坡店铺，SG/SGD 已实现域名与币种映射，但不能据此视为新加坡实店验收通过。

部分广告页会连续出现推广提示和“限时激励礼包”。此次普通客户端的 CLI 对 SVG 关闭按钮点击失败，验证时使用真实鼠标辅助关闭弹窗，再由同一次实际采集器读取、截图、校验和导出。正式采集器使用 Selenium 点击和 Actions 回退，并在截图前重新最大化窗口、等待无遮挡；此分支仍需在正式 Selenium 自动化客户端中补充无人干预实测。验证码、密码错误与未能关闭的遮挡均保留为未完成，不会伪装成功。
