# 寰球云联自动化平台 0.2.42 发布说明

发布日期：2026-08-26

## BS 商品ID查询改用 SKU 模糊搜索

1. 按用户最新要求，将搜索字段从旧版 `0.2.41` 的 Parent SKU 改为 **SKU**，继续选择 **Fuzzy Search**，支持使用子 SKU 查询。正式请求使用 `searchType="sku"`、`inquireType=0`。
2. 保持 **Views 降序**，只读取搜索结果第一条的 **Item ID**；不改为内部商品 ID，不跳过首条改取后续商品。
3. 查询范围仍为当前账号可访问的全部店铺中的 **Shopee 在售商品**，不触发商品或库存同步。
4. Excel 仍严格包含 `SKU`、`Item ID` 两列，均以文本保存。未匹配或查询失败的 SKU 保留，Item ID 留空；页面与日志区分未匹配和失败原因。
5. 沿用现有 BigSeller 账号管理、图形验证码配置、批量输入去重、结果预览及输出文件入口。单次最多 5000 个不同 SKU，页面最多预览 500 行，Excel 包含全部结果。

## 使用说明

1. 安装或更新至 `0.2.42`，从工作台或侧栏 BigSeller → Shopee 商品 → **BS 商品ID查询**进入。
2. 绑定并选择 BigSeller 账号，配置已有图形验证码服务。发布包不附带账号密码或登录会话。
3. 粘贴需要查询的 SKU（可包含子 SKU），选择输出目录后开始查询；搜索字段固定为 SKU，用户无需另行选择。
4. 完成后检查命中、未匹配及失败数量，再打开 Excel。旧版 `0.2.41` 的 Parent SKU 结果不能替代本次 SKU 搜索结果，需要时重新查询。
