# 1.0.14：ERP SKU 创建时间第一店铺有效候选优先回填与孤儿变体兼容

发布日期：2026-11-27。

- 优化「ERP SKU 创建时间第一店铺」的缺数判定规则：当输入 SKU 在 ERP 中同时存在**具备有效平台创建时间和店铺资料的商品记录**以及**少量历史已删除/归档无主表的孤儿变体记录**时，优先按所有有效商品候选选出每店最早商品并跨店排名，直接将最早店铺与最早平台创建时间回填至主列（「创建时间第一店铺」「最早平台创建时间」）及界面表格。
- 存在少量缺失主表、时间或店铺资料的历史孤儿记录时，在「创建时间对标说明」和明细工作表中备注“另有 X 条缺基础商品/时间/店铺资料的历史记录未参与排名”，不再将已有明确有效候选的老款 SKU 整行拦截为空。
- 仅当某个 SKU 在 ERP 中匹配的记录**全部**缺少有效创建时间或店铺资料（无任何有效候选）时，才标记为「数据待核验」并留空主回填列。
- 查询口径版本升级为 `erp-sku-earliest-store-v2`。

本版本基于独立桌面上游仓库 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main` 分支提交 `65e1096cc36e947b9f985fb4ba39e2271e2a9581` 及已发布的 `1.0.13` 提交 `ceb05ca6ec81b2858420c16bc13ddde70ca75667` 构建，保留既有全部桌面功能与内置连接配置。
