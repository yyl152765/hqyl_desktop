# 寰球云联自动化平台 0.2.63 发布说明

## 新增功能

- TEMU 余额统计：按订单创建月份筛选待处理款项，默认上个月；账户总金额取运行时当前页面。支持完整店铺名、批量采集、失败重试和 Excel 原始截图导出。
- Lazada 余额统计：采集 Income 待释放、Balance 总计余额、Ads 可用余额和最新提现状态；支持 PH、MY、TH、ID、VN、SG 站点配置和各自币种。
- 金额或截图未通过校验时，结果明确标为不完整；登录失败、页面超时及未知状态不会填成 0。不同币种不自动相加。

## 验证范围

2026-09-28 已完成一间 TEMU 店铺及 Lazada 五站点六间店铺的页面采集、原始截图和 Excel 核验。普通紫鸟客户端通过临时 CLI 适配器执行实际采集器，正式账号执行器的队列、清理与重试由自动化测试覆盖。

2026-09-30 追加菲律宾店铺验证中，收入、余额及最新提现状态通过，Ads 数值读到但截图被遮挡，整店结果为不完整。后续抽测由用户停止；用户随后要求打包。

余额模块保持试运行：新加坡站尚无可用店铺实测，正式执行器全自动关闭部分广告弹窗仍待验证。可关闭遮挡弹窗后重试失败店铺。

本包由当前工作区源码构建，构建清单记录提交号、未提交状态、签名状态和实际测试结果，分类为候选版本。打包检查不等同于全部店铺无人值守验收。
