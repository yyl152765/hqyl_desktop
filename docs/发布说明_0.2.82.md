# 0.2.82 发布说明

日期：2026-10-27。

## 本次新增

新增 TEMU“面单费与退货退款导出”。输入店铺名及日期范围，匹配完整紫鸟店铺名，并从名称首段提取运营名，依次导出发货面单费（已出账）、退货面单费和退货退款（售后单创建日期、退货退款、已退款）。

结果自动合并到一个 Excel，包含“发货面单费”“退货面单费”“退货退款”三个工作表。明细带运营和完整店铺名，退款页增加月份列；同类数据按店铺向下追加，保留长 ID、原始值及源表新增字段。页面提供“打开合并总表”。

逐店原始文件、处理后明细和批次清单均保留。无数据类别保留表头，部分失败明确标注“部分完成”；超过平台导出上限或校验不通过时显示错误，不将不完整结果标为全部成功。使用方式见 [TEMU 功能说明](temu_fee_refund_export.md)。

## 代码与依赖来源

本次按用户要求打包当前桌面工作区，没有执行上游拉取、合并或公开推送。桌面权威上游为 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main`，本次不宣称已重新核对其最新提交。父工作区提交及实际源码文件哈希分别记录在构建清单中，未创建 Git 合并提交。

共享运行依赖沿用 0.2.81 已验证快照：131 个 superbrowser Python 文件和 23 个 Mabang Python 文件逐项校验后复制到本版本独立构建目录。六份公开运行配置与上一版分发内容一致。保留此前 Shopee 支付确认、Lazada 账单、钉钉配置、国家店号简称匹配等功能。

## 验证与交付

发布回归测试 460 项通过，包含 TEMU 导出、合并、前端、输出目录与既有功能。首次测试命令中三个测试模块因测试目录未加入模块搜索路径而无法加载，调整测试命令后完整重跑通过，没有修改业务逻辑绕过断言。合并测试包含 65,537 行写出和读回。

开发阶段已通过两家店铺的 2026 年 9 月数据检查，合并行数分别为发货面单费 319 行、退货面单费 1 行、退货退款 2 行。该联调使用 CLI 网页适配器；桌面正式流程使用绑定账号的浏览器适配器，未将 CLI 联调描述为完整桌面 GUI 实店验收。打包过程不启动真实业务任务。

冻结程序在隔离目录中通过 `--self-check`，包括新页面入口及三个工作表的合成数据检查。安装包的冻结代码、前端资源、公开配置和最终 ZIP 校验结果以同版本构建清单及包验证报告为准。个人下载数据、样表、临时脚本、CLI 配置和浏览器数据不纳入安装包。
