# 寰球云联自动化平台 0.2.65 发布说明

## 本次更新

- 新增独立模块「BigSeller → Shopee 商品 → 新品认领时间查询」：导入 Excel，按主 SKU 查询创建时间最早的商品，从同一商品记录取得店铺、创建时间和上架时间，另存结果文件。
- 支持重复 SKU 去重、多 SKU 单元格拆分与对齐回填、逐项保存进度和失败后继续查询。保留原表已有店铺、时间、公式及其他工作表。
- BS 显示创建时间相同时继续比较有效的原始毫秒时间戳，避免同一分钟内选错店铺；时间仍按 BS 显示值导出。
- 马帮收支报表每次进入均不默认勾选仓库，三个雅仓也不默认选中，不自动恢复历史仓库选择。
- 验证码服务返回服务器错误时明确提示失败环节，避免误认为 BS 账号密码错误。
- 打包时使用独立的共享依赖副本，排除无运行时引用的补货脚本与历史缓存，清理已核实的内置凭据，不修改共享原源码。广告数据库同步改从运行机器的 `PGPASSWORD` 环境变量取得密码；未配置时原有同步会提示失败，不影响新品认领查询和 Excel 导出。钉钉等功能继续使用已有配置传入的凭据。

## 查询范围与验证

新品认领查询范围为当前账号可见的 Shopee 在售商品，支持全部站点或指定站点。上架时间采用同一商品的 BS「平台创建时间」，不代表已删除或已下架商品的完整历史记录。

2026-09-30 从用户原表抽取 8 行，包含 12 个不同 SKU、两行多 SKU 和一条重复行，通过实际桌面桥接调用真实 BS 接口完成导入、登录、查询及导出：5 个匹配、7 个在当前范围内未匹配、0 个查询失败。导出店铺和时间与接口最早记录一致，原文件哈希未变。已完成进度恢复时复用全部 12 项结果，未新增网络请求。尚未执行原表全部 8,873 个 SKU。

前端在 Edge 中验证仓库初始状态与重新进入状态均为未选择；浏览器交互使用模拟桌面桥接，真实 BS 验证另外使用实际桥接完成。版本构建检查、成品校验和交付哈希由本次实际发布记录补充。
