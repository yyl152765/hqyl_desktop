# 发布说明 0.2.20

发布日期：2026-07-23

## EchoTik 商品分页稳定性

- 修复 EchoTik 商品搜索分页存在重复商品时，接口标称 200 条但只能取得 171 个唯一商品、导致整批任务失败的问题。
- 默认排序分页不足时，自动使用 EchoTik 商品库支持的多个排序维度交叉补采唯一商品。
- 恢复出的候选商品按周期销量和商品 ID 在本地稳定重排，保证最终结果数量准确、商品 ID 唯一且顺序可复现。
- 正常分页能够一次取全时保持原流程，不增加额外请求。
- 所有恢复策略仍无法补齐时返回更准确的“多排序恢复仍不完整”错误。
