# 发布说明 0.2.24

发布日期：2026-07-27

## Shopee WORLD 卡邮箱验证码修复

- 修复 WorldFirst ID Check 页面将验证码发送到邮箱时，流程错误地继续查询短信库并一直停留在空白验证码页面的问题。
- 自动识别“电子邮件/邮箱 + 掩码邮箱”页面，创建现有钉钉验证码任务；接码人员录入邮箱中的验证码后，程序自动回填六位输入框并提交。
- 手机号验证码页面继续沿用原有 SMS 自动取码逻辑，不改变短信流程。
- 接码任务名称会带上页面显示的掩码邮箱，便于确认应该查看哪个邮箱；不会记录或输出真实验证码。

## 泰国273问题确认

- 泰国273 的 WorldFirst 页面显示验证码发送到 `p******2@1*6.com`，不是短信。
- 2026-07-27 的运行记录显示原流程在 WorldFirst 验证阶段超时；当前配置的两个 Shopee 主邮箱近期没有收到这类 WorldFirst 转发邮件，因此本次采用钉钉人工接码兜底，不依赖邮箱自动转发。
