## TEMU 东南亚在售商品批量导出（试运行）

从「紫鸟流程 → 在售商品导出」进入，粘贴完整紫鸟店铺名（每行一家）或勾选候选店铺，选择输出目录，匹配预览后开始导出。多家店铺依次处理，支持失败重试和继续未完成批次。

只导出在售中商品，保留全部申报价格状态、零库存和原始文件隐藏行。每店原始 Excel 单独归档，汇总第一列写入完整紫鸟店铺名。成功文件可复用，失败不会被记录成无数据或整批成功。

泰国009、菲律宾021两店已完成实机导出，共 15,310 行，汇总逐行核对通过。工作台保留试运行标记；下载中心、跨域下载、多文件拆分、平台单次导出上限等未支持场景会明确失败，不会静默生成截断结果。

## 运行条件和升级

- 每台电脑需安装紫鸟客户端和 ziniao-cli，完成各自的 API Key 授权及终端绑定，并登录相应账号。此功能读取本机 CLI 当前 profile；不会随安装包分发本机 API Key、账号、终端配置或店铺数据。
- 本次实际验证的版本为紫鸟客户端 6.26.6.26、CLI 1.1.2。其他版本仍需在对应电脑验收。
- 结束正在执行的任务并退出旧客户端后，运行 `HQYLAutomationSetup_0.2.58.exe`。启动后确认界面版本为 0.2.58。
- 原有安装位置及用户配置路径保持兼容；用户配置位于 `%APPDATA%\HQYLAutomation`，不在安装包中。
- 如需回退，退出新版后重新安装已保留的 0.2.57 安装包。保留用户配置和导出目录。
