# 爆款／旺款缺失仓库查询

入口：通用工具 → SKU库存与可售天数 → 查询内容“爆款／旺款缺失仓库”。

1. 绑定马帮账号，点击“加载开发人员”。
2. 搜索并勾选开发员，可选择一人或多人。
3. 选择“爆款＋旺款”“仅爆款”或“仅旺款”。
4. 点击“开始查询并导出”，页面显示结果，完整 Excel 保存到平台输出目录。

## 查询口径

- 款式直接使用马帮库存 SKU 的活跃度：`livenessType=1` 为爆款，`2` 为旺款，不根据商品名称或销量自行推算。
- 遍历所选开发员名下全部创建时间、全部商品状态的对应 SKU。
- 仓库全集来自库存 SKU 页面的 `defaultWarehouseId` 目录，不从命中 SKU 的仓库并集推导，避免遗漏完全没有关联商品的仓库。
- 优先使用仓库资料中的所属国家；未填国家时按名称中的国家、越南城市或明确国家代码识别。
- 排除中转仓、非东南亚仓。2026-09-21 用户明确确认 `1100808 / Ola-Ola海外仓`、`1100602 / T&C 海外 2 号仓-T&C海外仓` 不属于东南亚，固定排除。
- 暂按“未关联该 SKU”判断缺失。已关联的仓库即使库存为 0、负数，或仅有在途，也属于已覆盖。
- 一行一个 SKU，显示开发员、款式、缺失仓库名称、缺失数及已关联仓库数。已覆盖全部目标仓库的 SKU 仍保留，缺失数为 0。
- 新增但无法识别国家的仓库会在日志、页面和 Excel 查询口径中提示，避免静默忽略。

页面最多预览前 500 条，每页 50 条；Excel 导出全部结果，含“SKU缺失仓库”“东南亚仓库范围”“查询口径”三个工作表。没有命中 SKU 时仍导出表头和本次仓库范围。

原“SKU库存与可售天数”查询可从同一选择框切换，保留原创建时间范围与库存、未发货、在途口径。

## 实现和验证

新增服务 `backend/services/sku_warehouse_coverage.py`，通过现有 `start_sku_inventory_query` 桥接接口的 `query_mode=missing_warehouses` 调用。读取库存 SKU 与仓库目录，不修改马帮商品、仓库或库存。

仓库资料接口：`warehouse.dosearchwarehouse`，`attributetype` 留空时按“勾选、仓库名称、仓库类型、所属国家”列读取；仓库基准仍以库存 SKU 页面的完整下拉目录为准。

爆款、旺款分开请求 `stock.getStockList`，按开发员 ID 与款式核验返回数据。优先依据响应页数翻页，不因服务器限制单页条数而提前结束。遇到错误页码、重复分页或异常关联字段时停止导出，避免生成看似完整的结果。

2026-09-21 只读实测：一名开发员共 347 个爆款／旺款 SKU，成功对比 25 个东南亚非中转仓并导出。Ola-Ola 和 T&C 两仓未纳入这 25 个仓库。

回归测试覆盖：筛选参数、全部时间/状态、独立仓库全集、中转仓与明确排除仓、零库存已关联、无仓库关联、重复分页、接口分页条数限制、款式/开发员校验、Excel 完整性、页面选择和分页、历史库存结果兼容。
