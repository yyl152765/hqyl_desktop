# 寰球云联自动化平台 0.2.38 发布说明

发布日期：2026-08-22

## SKU 库存与可售天数查询分页修复

1. 查询分页改为读取马帮返回的真实当前页与总页数，到达末页后立即停止。
2. 增加重复分页保护：马帮把越界页回退到最后一页时，检测到相同 SKU 分页后自动结束。
3. 增加无新增 SKU 保护，避免接口异常情况下持续翻页到 500 页上限。
4. 保留 500 页异常上限作为最终安全保护。
