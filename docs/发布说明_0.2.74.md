# 0.2.74 发布说明

日期：2026-10-16。

本次同步独立公开仓库 `yyl152765/hqyl_desktop` 最新 main 提交 `c76e4578`（Add LZ warehouse inventory exports and scoped output directories），新增「lz 各仓实时库存」导出流程，并把广告数据、后台收支明细和 lz 库存的输出目录改为按工具独立配置。同时保留 0.2.73 的本地 Excel 折扣筛选批量导出工具、0.2.72 的 BigSeller 限流修复，以及之前的 Lazada、马帮、紫鸟等流程。

## 新增内容

- 流程入口：侧栏「马帮」分组新增「lz各仓实时库存」，Dashboard 同步新增对应卡片。开发入口：`python launcher/main.py --page=lz-warehouse-realtime-inventory`。侧栏马帮分组条目数 10 → 11。
- 库存导出：走马帮「商品 → 库存查询」同一套接口（`warehouse.searchwarehousestock` / `warehouse.getSearchWarehouseStockPage` / `warehouse.doexportwarehousestock`），**按所选仓库分别生成一份 xlsx**，每仓使用独立搜索 token；业务行不过滤不去重，零库存行保留；单页 10000 行、最多 1000 页。
- 仓库多选：页面自动读取本功能绑定的马帮账号，支持刷新仓库列表、搜索、全选当前结果，默认预选泰国 TH04 / TH05 / TH06；匹配不到 ID 的仓库进入 `failures`，其余照常导出。
- 独立输出目录（`backend/output_paths.py`）：新增 `SUPPORTED_TOOLS = {lazada_ads_data, lazada_bill_detail, lz_warehouse_inventory}`，作用域键为 `tool:country:kind`。
  - 广告数据固定 `桌面/log/lz泰国广告数据`。
  - lz 库存固定 `桌面/log/lz各仓库存`。
  - 后台收支按国家分别保存 `Lazada{国家}账单明细` 与 `Lazada{国家}账单明细截图`，切换国家立即生效。
  - 不再跟随其他功能最后选择的目录；自定义目录分别持久化在 `settings.tool_output_dirs`（`backend/config_store.py` 新增字段）。
- 桥接层：`backend/app_bridge.py` 新增 `lz_warehouse_inventory` 工具注册和 `get_lz_warehouse_inventory_info` / `get_lz_warehouse_inventory_warehouses` / `start_lz_warehouse_inventory` 三个方法；`lazada_ads_data`、`lazada_bill_detail` 改用新的目录解析接口。
- 新增测试覆盖输出目录作用域、按工具目录隔离、库存服务 / 桥接 / 前端 / 审核、脚本输出目录与 launcher 页面契约。
