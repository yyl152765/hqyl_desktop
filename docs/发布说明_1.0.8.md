# 1.0.8 Shopee 印尼整月收入账单

「印尼月度账单与税票下载」补上 My Income → Released 的整月收入 Excel，同时保留全部 Master Invoice 服务费账单与 Tax Invoice 税务发票 PDF。默认上一个完整自然月。

先扫描完整收入导出历史：已有整月报表直接下载，正在生成则刷新等待；只有确认不存在时才选择月初至月末并提交一次 Export。半月、跨月、错误站点和 Pending 报表不会当作目标账单。支持大店 Excel 的 Income / Seller Fee 编号分表，核对表内账期、印尼盾币种、文件完整性及 SHA-256。旧版仅税票批次提示补下载，保留原清单与原文件。

开发探查使用 `ziniao-cli`，桌面正式运行使用已有的紫鸟 WebDriver 和已绑定账号，不增加 CLI 运行依赖。仓发店专用差异不在本次范围，右侧 Income Statements 和 Itemised Billing 仍不下载。

本次基于已发布 1.0.7 的独立桌面检出完成。2026-11-25 已从权威仓库 `https://github.com/yyl152765/hqyl_desktop.git` 获取并核对 `main` 提交 `b9d1a39ceefbba0aa47dc3968747f21482b1dce6`，上游没有新变动；未将父工作区仓库当作桌面上游。保留既有完整版运行时、中台连接、Lazada 和钉钉功能。

CLI 已验证已有报表复用和缺失报表单次生成下载。WebDriver、自动回归、冻结自检、安装包解包核验及 OSS 公共下载的实际结果记录于同版本构建清单和发布验证记录。真实账单、个人配置、Cookie 和下载签名不进入源码及安装包。

四个更新文件发布到中台 OSS「自动化平台/」：版本安装包、版本构建清单、SHA256.txt、latest.json。先读回校验版本文件，再更新校验文件，最后发布 latest.json。员工可通过[免登录下载入口](https://hrms.whhqyl.com.cn/desktop-updates/latest.json?download=1)或客户端检查更新获取，`mandatory=false`。
