# 发布说明 0.2.16

发布日期：2026-07-16

## 本次变更

- 新增 Lazada 提现统计流程，支持菲律宾、马来西亚和泰国店铺。
- 菲律宾、马来西亚按上月日期筛选提现流水，生成逐店 Excel；固定表头为“交易时间、类型、金额、备注、国家、店铺”。
- 支持中英文 Lazada 页面、多行备注、负数金额、跨页抓取、流水去重和无数据空表。
- 泰国下载统计期内的 `Order Details` 文件，并校验账单号、账期后上传。
- 所有成功产物按“国家 / 月份 / 店铺”结构上传钉盘，同名文件覆盖更新。
- 新增 EchoTik 商品达人采集入口，支持泰国商品库关键词采集和达人导出。

## 测试
