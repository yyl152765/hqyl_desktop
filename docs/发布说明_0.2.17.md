# 发布说明 0.2.17

发布日期：2026-07-16

## 本次变更

- 修复 Shopee 马来西亚、泰国广告充值在 WorldFirst ID Check 页面停留、未点击“获取短信验证码”的问题。
- WorldFirst 验证控件支持普通文本节点及其可点击父节点，不再局限于原生按钮标签。
- 支持递归扫描嵌套 iframe，最大深度为 8 层，并记录命中的窗口、iframe 路径与扫描深度。
- 点击短信验证控件后校验 OTP 输入框是否出现；页面无变化时重新定位并重试，最多 3 次。
- 收紧 OTP 输入框识别规则，避免将普通输入框误判为短信验证码输入框。
- 增加 WorldFirst 等待进度和超时诊断日志，便于定位窗口、iframe 或页面状态问题。
- 优化 Shopee 广告消费日期范围选择，提升不同页面结构下选择最近 7 天的稳定性。
