# 发布说明 0.2.15

发布日期：2026-07-14

## 本次变更

- 兼容 Shopee 越南卖家中心新增的 `unified-popup` 远程活动弹层，仅关闭当前可见弹框，避免隐藏模板干扰。
- Shopee 越南广告充值遇到 `no such window`、`web view not found` 等 WebDriver 窗口会话中断时，自动关闭店铺并重开重试，最多 3 次。
- 修正批次结果汇总：存在失败店铺时不再把整个任务记为成功，并输出成功、处理中、跳过和失败数量。
