# 0.2.89 财务导出与 SKU 参考价筛选

本版合入桌面上游 `main` 的 `f05b9a346762d37127b627a836038c891eba9226`（2026-11-04），保留当前桌面工作区的业务修复。

## 新增与修复

- TEMU 财务报表导出：从「账户资金 → 对账中心」按自定义日期导出列表及账务详情，下载全球财务明细。每个 sheet 首列写入完整紫鸟店铺名，不同店铺的同名 sheet 合并，保留两行分组表头与原始数据。
- 兼容对账中心实际域名跳转和全球中心授权页；仅识别本次下载新开的授权页，并核对目标区域及店铺。登录页读取不再反复切换标签页。
- Excel 折扣筛选可选 SKU 参考价格表，按卖家 SKU 精确匹配；低于参考价格的行单独记录，支持查看及另存删除 SKU 明细。原活动表和参考价格表保留。
- 纳入 TEMU 面单费与退货退款、活动模板导出等当前本地功能，以及 KEC 对账、Lazada 账单和紫鸟驱动兼容修复。
- 保留 Lazada 受限账单流程、钉钉保存配置与操作人选择、国家店号简称匹配和手动可选更新。
