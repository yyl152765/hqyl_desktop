# 1.0.13：ERP SKU 创建时间第一店铺

发布日期：2026-11-27。

- 新增「ERP 数据库 → ERP SKU 创建时间第一店铺」：直连 ERP 只读库，按完整 SKU 精确匹配（区分大小写）Shopee 全部商品状态及 ERP 仍留存的商品/变体归档记录，无需登录 ERP 或打开浏览器。
- 先求每家店铺最早的商品平台创建时间（`shopee_item_base_info.create_time`，ERP `Asia/Shanghai` 业务本地时间），再选所有候选店铺中最早者；并列时按 `shop_id`、`item_id`、`model_id` 升序稳定展示一家，并在说明与明细中输出并列店铺数和清单。
- 支持单个或多个 SKU 输入、`.xlsx` / `.xls` 导入（前 10 行识别“库存SKU编号”“库存SKU”“SKU”，优先“动销总表”），支持站点与 Shop ID 筛选及 SQLite 断点恢复。
- 结果区分「已匹配」「ERP留存范围未找到」「数据待核验」「查询失败」「未执行」：缺基础商品、创建时间、店铺资料或变体标记时标为数据待核验，保留最早已知候选但不回填正式“创建时间第一店铺”列；连接异常或超时记为查询失败，不会误判为未找到。
- 每次运行在输出目录下生成独立文件夹，包含原表回填与「ERP创建时间对标明细」「ERP创建时间对标汇总」的工作簿、`summary.json`、`process.log` 和进度文件；源文件不覆盖，存在未确认项时文件名与任务均标记“结果不完整”。

本版本基于独立桌面上游仓库 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main` 分支最新提交 `65e1096cc36e947b9f985fb4ba39e2271e2a9581`（已包含 1.0.12 Shopee 印尼多月份并发下载及 Lazada 活动模板折扣筛选与旧版 Excel 兼容），保留 Lazada 受限账单流程、钉钉保存配置与操作人选择、国家店号唯一匹配，以及既有内置充值连接配置。父工作区仅作为新功能开发与审查来源，不作为桌面发布的 Git 合并历史。
