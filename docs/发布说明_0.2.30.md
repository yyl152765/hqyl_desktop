# 寰球云联自动化平台 0.2.30 发布说明

## Shopee 马来广告充值

1. 修复月初执行“过去 7 天”时，目标日期跨月但日期面板只显示当前月和下月，导致批量店铺在付款前失败的问题。
2. 目标开始日期不在当前面板时，优先执行“上一月”导航，再按目标起止日期精确选择。
3. 快捷项改为完整标签精确匹配，避免误点“今天、昨天、过去 7 天、过去 30 天”外层容器。
4. 新增 `2026-07-28 ~ 2026-08-03` 跨月回归用例。

## 发布安全

1. PyInstaller 不再打入源码中的全局 `config.yaml` 或完整 Shopee 配置目录。
2. 构建时仅生成五个站点的脱敏运行配置，保留任务、站点和表格元数据。
3. 紫鸟密码、钉钉 token/secret、邮箱授权等凭据不进入安装目录。
4. Shopee 表格模式所需钉钉 App 凭据由桌面端绑定设置在任务运行时注入内存。
