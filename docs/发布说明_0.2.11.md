# 发布说明 0.2.11

发布日期：2026-07-10

## 本次变更

- 新增 EchoTik 泰国商品库与商品达人采集流程。
- 支持绑定 EchoTik 账号，并通过登录接口自动获取访问令牌。
- 支持一次输入多个搜索关键词，兼容换行、英文/中文逗号和分号。
- 每个关键词自动采集全部商品分页，并逐个采集商品详情中的全部达人分页。
- 同一商品命中多个关键词时自动合并关键词，只采集一次达人，避免重复数据和重复请求。
- 商品与达人数据导出到同一个 Excel，分别写入 `Products` 和 `Creators` 工作表。
- 修复 EchoTik 每页数量填写 `50` 时被浏览器判定为无效的问题。

## 测试
