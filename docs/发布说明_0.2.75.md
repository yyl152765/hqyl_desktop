# 0.2.75 发布说明

日期：2026-10-19。

本次修复 Lazada 提现统计：菲律宾、马来西亚店铺的 My Balance 明确未开放时，自动复用泰国收入账单下载流程，保持当前国家、统计日期和钉盘目录。

## 更新内容

- 余额页受限后进入“我的收入 → 收入账单”，逐页选择与统计日期相交的账期，下载 `Order Details`；校验 XLSX/CSV 内部账单号和账期后才上传。
- 菲律宾、马来、泰国共用收入账单业务实现，支持英文和中文页面，不跨国家跳转或归档。
- 修复 Finance 菜单重复展开/收起，以及只有侧栏文字却被当成余额页的误识别。
- 收入账单空态需要连续稳定确认；加载失败、漏解析、重复页、分页异常、导出登录失效均保留明确结果，不能报完整成功。
- 并发日志附带店铺名称；受限页面留本地诊断截图；界面按账单文件个数展示兜底产物。
- 保留 0.2.74 的 lz 各仓实时库存导出和各工具独立输出目录。
