# 寰球云联自动化平台开发方案

## 1. 目标

新建 `hqyl_desktop` 项目，专门承载寰球云联内部桌面客户端开发。原 `mabang_process` 保留为自动化逻辑来源，新项目逐步迁移通用工具类和高频业务工具，后续也接入紫鸟 WebDriver 相关流程，最终输出可安装且可在线更新的 Windows 客户端。

第一阶段目标：

- 建立独立项目结构。
- 做出 H5 风格桌面壳。
- 迁移一个完整工具样例：SKU 采购日志查询。
- 准备 EXE 和安装包构建脚本。
- 预留远程更新清单和紫鸟流程模块。

## 2. 技术路线

当前采用：

- `pywebview`：提供 Windows 桌面窗口，并让前端调用 Python 方法。
- `HTML/CSS/JavaScript`：第一版先用静态前端，减少工程复杂度。
- `Python service`：承载马帮登录、查询、导出等业务逻辑。
- `PyInstaller`：打包成用户无需安装 Python 的程序目录。
- `Inno Setup`：把程序目录封装成安装包。

后续如果页面复杂度上来，可以把 `frontend` 替换为 `Vue 3 + Vite + Element Plus`，后端接口层不需要推倒重来。

## 3. 架构分层

```text
frontend
  表单、日志、状态、结果展示

pywebview bridge
  把 Python 方法暴露给 H5 页面

backend task
  后台线程、任务状态、运行日志、错误捕获

backend services
  具体业务工具，例如 SKU 采购日志查询、紫鸟店铺流程

backend core
  马帮客户端、紫鸟 WebDriver 客户端、通用请求、配置、文件等工具
```

## 4. SKU 采购日志查询样例

样例代码位置：

```text
backend/services/purchase_log.py
frontend/pages/purchase-log.html
frontend/assets/pages/purchase-log.js
frontend/assets/common.js
```

迁移方式：

1. 从原 `SKU采购日志查询导出工具.py` 提取业务逻辑。
2. 删除 Tkinter UI 依赖。
3. 新增 `PurchaseLogQuery` 作为任务输入。
4. 新增 `run_purchase_log_query()` 作为后端统一入口。
5. 前端通过 `window.pywebview.api.start_purchase_log_query()` 启动任务。
6. 前端轮询 `get_task_status()` 展示日志和结果。

运行流程：

```text
用户输入账号、密码、SKU、日期、输出目录
  -> H5 调用 AppBridge
  -> AppBridge 校验参数
  -> TaskManager 创建后台任务
  -> purchase_log 登录马帮并查询
  -> pandas 导出 Excel
  -> 前端显示导出文件和日志
```

## 5. 工具类迁移原则

不要直接整文件搬旧脚本。优先按职责拆分：

- `util/mabang_client.py` 中稳定的登录、请求能力迁到 `backend/core/`。
- 紫鸟 WebDriver 能力独立沉淀到 `backend/core/ziniao_client.py`，通过本地 HTTP IPC 管理店铺窗口和调试端口。
- 每个业务脚本拆成一个 `backend/services/*.py`。
- Tkinter、messagebox、窗口线程等旧 UI 代码不迁移。
- 账号密码等敏感信息不写入项目默认配置。
- 需要长期复用的 Excel、钉钉、数据库能力再沉淀到 `backend/core/`。

## 6. 安装包交付

交付物建议命名：

```text
HQYLAutomationSetup_版本号.exe
```

安装后：

- 程序安装到 `%LOCALAPPDATA%\Programs\HQYLAutomation`，普通用户无需管理员权限。
- 创建桌面快捷方式。
- 创建开始菜单快捷方式。
- 用户配置写入 `%APPDATA%\HQYLAutomation`。
- 本地日志写入 `%LOCALAPPDATA%\HQYLAutomation\logs`。

## 8. 风险点

- 马帮页面结构和接口字段可能变化，需要把解析逻辑集中在 service 层。
- pywebview 依赖 Windows WebView2，部分旧电脑可能需要单独安装运行时。
- PyInstaller 打包 Selenium、pandas、openpyxl 类依赖时，需要逐个工具验证。
- 内部账号密码不能放入默认配置或打包产物。
