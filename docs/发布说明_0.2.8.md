# 发布说明 0.2.8

发布日期：2026-07-03

## 本次变更

- 修复 Shopee 马来广告充值中“过去7天消耗金额”抓取错误的问题。
- “过去7天”口径调整为不含当天的最近 7 个自然日，即 `T-7 ~ T-1`。
- 优化 Shopee 广告页日期选择器识别逻辑，支持中文月份标题，例如 `六月2026`、`七月2026`。
- 日期面板无法识别月份时，不再按单独日期号点击，避免跨月时把 `2026-07-02` 误选成 `2026-06-02`。

## 问题复现

用户反馈马来站点充值表中“过去7天消耗金额”异常。现场探查 `李坤-马来215-MY004` 后确认：

- 旧逻辑传入区间：`2026-06-25 ~ 2026-07-02`。
- 页面实际选中：`02/06 - 25/06 (GMT+8)`。
- 页面读到花费：`RM3.8k`，对应表格中的 `3800`。

根因是 Shopee 日期面板跨月显示中文月份，旧脚本无法识别面板月份，只按日期号匹配，导致误点。

## 修复验证

修复后同一店铺现场验证：

- 目标区间：`2026-06-26 ~ 2026-07-02`。
- 页面实际显示：`26/06 - 02/07 (GMT+8)`。
- 页面读到花费：`RM1.2k`。

