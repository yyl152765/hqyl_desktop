# 寰球云联自动化平台 0.2.52 发布说明

发布日期：2026-09-10。升级版本：`0.2.51` → `0.2.52`。

## 更新内容

- 新增「TEMU 发货渠道更改」模块，支持导入「每日随机长宽高」Excel，按表格顺序设置渠道长、宽、高和重量。
- 只处理已开启（ON）的渠道；关闭（OFF）的渠道跳过，不占用 Excel 行。待处理数量以查询到的开启渠道为准。
- 预览固定渠道与 Excel 行的对应关系，支持进度保存和失败后继续；旧版包含关闭渠道的预览需要重新查询。
- 每条提交前复核渠道开启状态，保存后读取并核验结果，保留原有其他渠道设置。

## 使用方式

进入「TEMU 发货渠道更改」，选择已配置的马帮账号并导入 Excel，查询渠道后检查预览，再开始执行。

Excel 中的公式使用文件内已保存的计算结果。请先在 Excel 中打开并保存当天文件，再导入本模块。

## 发布文件

- `HQYLAutomationSetup_0.2.52.exe`：客户端安装程序。
- `HQYLAutomation_ServerUpload_0.2.52.zip`：服务器上传包，含安装程序、更新清单、SHA-256、构建清单和部署脚本。
- `HQYLAutomation_0.2.52.zip`：客户端分发包。
- `HQYLAutomation_0.2.52_BUILD_MANIFEST.json`：构建与验证记录。
- `HQYLAutomation_0.2.52_PACKAGE_VERIFICATION.json`：最终压缩包校验记录。

## 更新源部署

将服务器上传包复制到服务器并解压，执行其中的 `部署更新源.bat`。默认发布目录为 `C:\inetpub\wwwroot\hqyl`；若服务器实际站点目录不同，先修改 `deploy.ps1` 中的 `$SiteRoot`。

部署脚本先校验并复制安装程序，最后更新 `latest.json`，同时保留旧清单备份。更新源地址为 `http://rpa.whhqyl.com.cn/hqyl/latest.json`。
