# 寰球云联自动化平台 0.2.55 发布说明

发布日期：2026-09-11。升级版本：0.2.54 → 0.2.55。

## 广告数据及充值校验修复

- 越南盾、印尼盾的千位分隔点按整数货币解析；消耗、余额和两次付款确认使用同一严格规则。空值、缩写、错币种或无效格式不再变成有效零金额。
- 七天统计按 GMT+7 的前七个完整自然日采集。必须确认本次对应日期的 Shopee 统计响应成功，并与页面 Expense 一致且稳定，才能写表。
- 日均消耗统一除以7，十天预算由程序独立重算；保留越南百位、印尼万位预算取整及待充值差额的万位取整。
- 写表先置“待核验”，逐步写入并读回校验。缺数、日期不符、数据过期、错误限额、未知人工覆盖等都停止该店自动充值。
- 独立读取限额源表，校验阈值完整、非负且严格递增，I/J必须引用本行及本国完整分档表。即使派生结果被手填成有效数字，缺失阈值仍会阻断付款；放行前再次读取源表，变化即停止。限额不合格时仍可保存已验证的消耗和余额。
- 保留人工充值金额。人工 O 列在自动模式中需要审核；现有明确指定金额的自定义充值模式保留，并使用严格付款金额校验。
- 同一店铺在桌面及独立服务间共用数据库执行锁，覆盖采集、支付及余额复核；超时后台线程未退出时继续持锁。仓发店保留完整公司名称以区分店铺。
- 表格排序后，执行结果按唯一店铺身份重新定位再写；写回失败不会触发重复付款。
- 每次采集保存本地审计证据，包含原始金额、日期、解析版本和校验结果。HQYL 执行环境使用规定的输出目录。

## 使用与升级

结束当前任务后正常退出旧版程序，安装 `HQYLAutomationSetup_0.2.55.exe`，从新的快捷方式启动并确认版本为0.2.55。所有参与广告充值的执行机都需要更新；已经运行的旧进程不会因源码或安装包更新而自动获得修复。

新版本正常采集并通过全部校验后，才会把对应店铺恢复为正确的充值状态。本次维护未发起实际充值，未发布服务器更新源，也未终止用户现有进程。
