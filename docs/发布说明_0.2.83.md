# 0.2.83 发布说明

日期：2026-10-29。

## TEMU 导出修复

- 消息面板遮住顶部“消息”入口时，改用该面板内的关闭按钮；操作中延迟出现的消息面板，仅在确认原点击被拦截、尚未执行时关闭并补点一次。不重复未知结果的导出提交。
- 正式桌面浏览器在点击前等待目标位置稳定、中心可命中，避免抽屉和下拉框动画尚未完成时点击；持续遮挡仍报错，不强制穿透弹窗。
- 面单费用按唯一标签关联币种、账单数和总金额，并等待汇总及表格加载完成。暂时显示 `--` 时继续等待，不直接报错或认定为零账单。
- 关闭店铺请求无响应时，继续核验本任务店铺的原调试端口；明确退出后才允许下一店。认证失败、明确拒绝关闭、端口仍开放时继续暂停。
- 导出和关闭同时失败时保留两段原因，避免清理错误覆盖原始页面错误。

三项导出条件、运营与店铺名、三工作表合并及逐店原始文件保留方式不变，见 [使用说明](temu_fee_refund_export.md)。

## 验证与构建来源

本次使用正式桌面 `ZiniaoBrowser` 账号与浏览器适配器进行实店验证。最初马来店铺两项面单导出成功，退款出现一次间歇遮挡；后续补充点击前命中与动画等待，并修复泰国零结果仅刷新表格的情况。最终两店六项导出全部通过：马来 219/1/2 行，泰国 100/0/0 行，合并总表重新读回核对为 319/1/2 行。零数据两项均经过平台查询/新任务验证。

最终发布回归 516 项全部通过，冻结程序隔离自检通过；82 个桌面模块、40 个既有共享模块、67 个前端文件、六份公开配置及 1,270 个分发文件通过审计。实店验收使用与正式程序一致的原生浏览器适配器源码路径，未声称安装后的完整 GUI 操作已验收。证据及文件哈希记录在同版本构建清单和包验证报告中。

本次打包当前工作区修复，没有拉取上游、创建 Git 合并提交或公开推送。桌面权威上游仍为 `https://github.com/yyl152765/hqyl_desktop.git` 的 `main`，父工作区提交单独记录。

原构建临时目录已清理，因此根据 0.2.82 构建清单及安装包恢复共享依赖：125 份共享 Python 源码按哈希核验，一份共享模块使用旧安装包中的同版字节码；五份旧清单中列出但旧安装包未分发的日表现源码不引入。Mabang 23 份源码和六份公开运行配置保持与 0.2.82 一致。不会以当前共享目录中的未核验变动替换旧版依赖。

交付包括 `HQYLAutomationSetup_0.2.83.exe`、`HQYLAutomation_ServerUpload_0.2.83.zip`、构建清单、校验清单和包验证报告。本次仅生成本地未签名安装器和上传包，不执行安装、远程上传或部署。
