# 1.0.1 桌面版发布说明

- 「马帮流程」新增「菲律宾取消订单同步退款」。查询菲律宾 Shopee 店铺当前的取消订单异常列表，导出预览清单。核对后确认同步，工具将复查预览中的订单，按批请求马帮同步订单信息，再查询异常列表。
- Excel 包含汇总、概览和原始数据。同步后的文件增加「同步结果」，记录每笔订单对应的批次回执和复查状态。批次回执表示马帮对同步请求的处理情况。退款进度以平台实际状态为准。
- 预览与绑定账号对应，有效期 15 分钟。马帮要求人工确认的批次会列在结果中。回执未知时停发后续批次并保留同步记录，供人工核对。
- 合入独立桌面仓库的电子税务局申报和活动价相等时按折扣改价功能。申报页面提供导出查询和需确认的正式申报入口。
- 保留 TEMU 在售商品导出的登录修复、Lazada 广告月报与后台账单、BigSeller 链接抓取、马帮仓库月报导出、各组销量报表输出目录修复及钉钉操作人配置。

在「设置」绑定并选择马帮账号，再进入工具。先点「查询并预览」，核对订单后勾选确认并点「同步订单」。通过「打开结果」查看 Excel。原定时流程仍可按现有方式运行，桌面入口采用手动触发。

服务器更新文件使用同版本的 `HQYLAutomation_ServerUpload_1.0.1.zip`。安装程序、更新清单和 SHA-256 记录随包提供。
