# 寰球云联自动化平台 0.2.62 发布说明

新增爆款／旺款缺失仓库查询。入口：通用工具 → SKU库存与可售天数 → 查询内容“爆款／旺款缺失仓库”。

- 加载并选择开发员，支持搜索、多选，以及仅爆款、仅旺款或两类一起查询。
- 查询所选开发员名下全部创建时间、全部商品状态的对应 SKU。
- 每个 SKU 展示款式类型、缺失的东南亚仓库、缺失仓库数和已关联仓库数。
- 仓库范围不含中转仓；明确排除 Ola-Ola海外仓、T&C 海外 2 号仓-T&C海外仓。
- “缺失”按未关联 SKU 判断；已关联但库存为 0 或负数的仓库仍算已覆盖。
- Excel 包含完整结果、本次仓库清单及查询口径。原库存与可售天数查询可在同一页面切换使用。

真实马帮数据验证：一名开发员共 347 个爆款／旺款 SKU，成功完成 25 个目标仓库的对比并导出。

发版前 102 项回归测试通过，无失败、错误或跳过；源码自检通过。成品自检包含新 SKU 服务、零库存关联判断、指定仓库排除以及 Excel 内容核对，使用模拟数据及独立配置目录。
