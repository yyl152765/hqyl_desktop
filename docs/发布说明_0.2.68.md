# 0.2.68 广告充值数据库配置修复版

修复 0.2.67 升级后，广告充值在创建运行记录前报 `fe_sendauth: no password supplied` 的问题。该错误发生在店铺充值开始之前。

## 升级后的操作

1. 安装 0.2.68，打开「设置 → 广告充值数据库」。
2. 若此前未配置数据库密码，由管理员填写数据库密码，点击「保存并验证连接」。此处不是紫鸟或店铺登录密码。
3. 显示连接验证通过后即可重新启动充值，无需重新打开客户端。已有 `HQYL_GUARD_DB_PASSWORD` 或 `PGPASSWORD` 配置仍兼容；已用修复脚本保存的 Windows 用户变量也可读取。

安装包不包含数据库密码，安装本身不会自动补上缺失凭据。新设置使用 Windows 当前用户的 DPAPI 加密并单独保存在本机 `%APPDATA%/HQYLAutomation/ads_database.json`，不返回或回显密码，不影响其他账号和设置。此文件不能直接跨 Windows 用户迁移。输入新密码时先只读验证，验证失败保留旧配置；留空只验证已存配置。

## 修复范围

- 增加数据库配置入口、密码状态和只读连接检查。
- 保存的密码立即传入充值防重模块和数据库同步模块；在模块已导入后修改密码也能生效。
- 缺失或无效配置在加载店铺流程前阻止启动，并给出可操作的中文提示；不绕过充值权限、重复付款防护和金额核验。
- 保留 0.2.67 的 Product Ads 报表切换、印尼语金额标签和待核验原因修复。人工固定金额仍需审核。
